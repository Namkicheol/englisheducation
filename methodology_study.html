🎯 1 CLT Communicative Language Teaching ▼
CLT Conditions
CLT는 communicative activity, authentic material, small groups, functions and forms의 균형, fluency와 accuracy의 상보성을 강조합니다.

Communicative activity에는 information gap, learner choice, feedback이 들어갑니다.

📋 기출 이력

2010 Q16 — focus on form과 communicative activity 맥락

2026 A-7 — communicative drill과 information gap 맥락

Notional Functional Syllabus
Functional syllabus는 learner가 수행할 communicative functions나 speech acts를 중심으로 구성됩니다.

Grammar syllabus보다 language에 대한 넓은 관점을 반영하지만 atomistic approach가 될 수 있습니다.

🔎 2 TBLT task-based instruction ▼
Task Features
Task는 work plan이며, primary focus on meaning, natural language use process, clearly defined communicative outcome을 갖습니다.

Task completion 자체가 중심이며 language form은 task 수행 중 필요에 따라 다뤄집니다.

📋 기출 이력

2017 B 서술3 — TBLT task 유형과 form focus 통합 맥락

2023 B-10 — task-based language test 맥락

Target vs Pedagogical Task
Target task는 classroom 밖 real-world activity이고, pedagogical task는 classroom에서 communicative language use를 유도하도록 설계된 activity입니다.

Rehearsal task는 real-world counterpart와 명확한 관계가 있고, activation task는 직접 대응이 약합니다.

🔎 3 Task Types task classification ▼
Gap Tasks
Information-gap은 정보 교환, opinion-gap은 preference·feeling 교환, reasoning-gap은 주어진 정보에서 새 정보를 추론하는 task입니다.

Reasoning-gap은 timetable로 best route 찾기처럼 inference process가 필요합니다.

📋 기출 이력

2026 A-7 — information gap 활동 맥락

Psycholinguistic Classification
Jigsaw, information-gap, problem-solving, decision-making, opinion exchange는 interactant relationship, interaction requirement, goal orientation, outcome option으로 구분됩니다.

Jigsaw는 two-way information gap, required interaction, convergent goal, closed outcome의 성격이 강합니다.

🔎 4 PPP and TBLT procedure comparison ▼
PPP
PPP는 Presentation → Practice → Production 순서로 target form을 제시하고 통제 연습 후 산출로 이동합니다.

초급자와 accuracy focus에는 유용하지만 communication이 후반부에 제한적으로 나타날 수 있습니다.

TBLT Cycle
TBLT는 task 수행을 중심으로 pre-task, task cycle, language focus가 연결됩니다.

Meaning-oriented task 수행 후 learner language를 바탕으로 form focus가 일어날 수 있습니다.

🔎 5 Designer Methods classic methods ▼
Designer Methods
Silent Way, Suggestopedia, TPR, CLL, Natural Approach는 각기 다른 theory와 classroom technique을 가진 designer methods입니다.

TPR은 command와 physical response, Natural Approach는 comprehensible input과 low affective filter를 강조합니다.

🔎 6 Post-method principled eclecticism ▼
Post-method Era
Post-method 관점은 단일 method 처방보다 local context, teacher judgement, learner needs에 맞춘 principled decision을 강조합니다.

Principled eclecticism은 여러 방법을 무작위로 섞는 것이 아니라 coherent rationale에 따라 선택하는 것입니다.
