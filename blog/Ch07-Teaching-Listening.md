## ① 개념 정의

### Background Knowledge — Schemata & Scaffolding

> "The lack of shared schematic knowledge makes comprehension difficult or even impossible."

듣기 이해는 언어 지식만으로 이루어지지 않는다. 학습자가 가진 **<span style="color:#3182ce">background knowledge</span>**가 충분히 활성화되어야 청해가 가능해진다. 이 배경지식은 두 유형으로 나뉜다.

- **<span style="color:#3182ce">Content schemata</span>**: world/topic knowledge — 주제에 대한 내용 지식
- **<span style="color:#3182ce">Formal schemata</span>**: rhetorical/discourse structure — 텍스트 구조에 대한 지식

**<span style="color:#3182ce">Paused listening tasks</span>**는 녹음을 여러 구간으로 나눠 각 pause마다 학생이 주제를 적는 기법이다. Content schemata를 활성화하고 **<span style="color:#3182ce">metacognitive awareness</span>**를 높이는 **<span style="color:#319795">scaffolding</span>**의 일종으로 평가된다.

---

### Input Types — Roughly-tuned vs Finely-tuned

> "Roughly-tuned input: Input that is only accustomed at approximate level of Ss' proficiency. This is closer to natural usage of language."

**<span style="color:#3182ce">Roughly-tuned input</span>**은 학습자 숙달도에 대략적으로 맞춘 입력으로, 자연스러운 언어 사용에 가깝다. **<span style="color:#3182ce">Finely-tuned input</span>**은 학습자가 이미 배운 구조와 어휘만 포함하도록 세심하게 통제되어 목표 문법을 명확히 제시한다.

<span style="color:#c53030">⚠️ 자주 출제되는 반전 함정</span>: 시험에서 두 개념의 정의가 뒤바뀐 채 제시된다. Roughly-tuned ≠ 세밀하게 통제된 것. Roughly = 대략적·자연스러운, Finely = 세밀하게 통제된.

**<span style="color:#3182ce">Concocted texts</span>**는 인공적으로 단순화한 텍스트로, 교실 밖 실제 청취로의 transfer를 방해하는 **false expectation**을 형성한다. 속도를 부자연스럽게 낮추는 것도 clustering, reduced forms 등 구어 특성을 손상시킨다. 대안: 구문과 문장 사이에 **<span style="color:#319795">pauses between phrases and sentences</span>**를 삽입.

---

### Authentic Materials — 3 Strategies

> "Grading the texts: T can collect a large enough sample of authentic speeches and sequence them from the text which is more accessible to lower-level Ls to what is more appropriate to advanced Ls."

Authentic materials를 사용할 때 교사가 취할 수 있는 세 가지 전략:

| 전략 | 대상 | 방법 |
|------|------|------|
| **<span style="color:#3182ce">Simplifying the tasks</span>** | task 단순화 | 입력(텍스트)은 그대로, 과제를 쉽게 |
| **<span style="color:#3182ce">Grading the texts</span>** | 텍스트 배열 | 접근 가능한 텍스트 → 고급 텍스트 순서 배열 |
| **<span style="color:#3182ce">Staging the listening</span>** | 활동 점진화 | 같은 텍스트에 대해 활동을 점진적으로 구성 |

<span style="color:#c53030">⚠️ 혼동 주의</span>: Staging the listening = "graduated activities, build up understanding little by little" — Grading the texts와 혼동하지 말 것.

---

### Functions of Listening — Transactional vs Interactional

> "Interactional language function: A function of spoken texts whose objective is to promote social relationship between interlocutors; person-oriented."

| | **<span style="color:#3182ce">Transactional</span>** | **<span style="color:#3182ce">Interactional</span>** |
|-|------|------|
| 목적 | 정보 전달 | 사회적 관계 유지 |
| 초점 | message-oriented | person-oriented |
| 예시 | factual info, confirmation checks | phatic communion ("Nice day, isn't it?") |

---

### Processing — Bottom-up / Top-down / Interactive

> "Bottom-up Processing: Listening is a process of decoding the sounds that one hears in a linear fashion. Moving from the parts to the whole."

**<span style="color:#3182ce">Bottom-up processing</span>**은 소리를 선형적(linear)으로 해독하여 parts → whole로 의미를 파악한다. 언어 form에 초점을 두며 listening for details에 적합하다.

**<span style="color:#3182ce">Top-down processing</span>**은 prior knowledge와 context를 활용해 의미를 재구성한다. Extralinguistic skills에 의존하며 global strategies에 해당한다.

**<span style="color:#3182ce">Interactive processing</span>**은 두 방식을 동시에 사용한다.

- <span style="color:#c53030">⚠️ level 배분 반전 함정</span>: **beginners → bottom-up**, **advanced learners → top-down**. 시험에서 반전 제시.
- Interactive processing은 level-differentiated lesson에 적합하다 — 초급은 bottom-up, 고급은 top-down에 각각 집중 가능.

---

### Types of Listening Practice — 6유형

> "Reactive Listening: Ss simply listen to the surface structure of an utterance to repeat it back to the T."

**<span style="color:#3182ce">Reactive listening</span>**: 단순 반복(repeat back) — surface structure
**<span style="color:#3182ce">Responsive listening</span>**: 교사의 짧은 발화에 적절한 반응(appropriate response) 생성 — T가 output을 push
**<span style="color:#3182ce">Selective listening</span>**: planned purpose로 특정 정보 수집 — scanning과 유사, field-independent 학습자 적합, **longer** discourse
**<span style="color:#3182ce">Extensive listening</span>**: longer stretch of speech, 전체 이해, **top-down** skills 발달
**<span style="color:#3182ce">Intensive listening</span>**: 짧은 텍스트 반복 재생(repeated replay), 언어 분석, **bottom-up** skills
**<span style="color:#3182ce">Interactive listening</span>**: speaking과 통합된 authentic give-and-take

<span style="color:#c53030">⚠️ 혼동 주의</span>: Selective = **longer** / Intensive = **shorter**. Extensive = top-down / Intensive = bottom-up. 시험 단골 반전.

---

### Listening Strategies — 9유형

**<span style="color:#3182ce">Predicting</span>** (pre-listening): 들을 내용을 예측 → schemata 활성화 → comprehension 준비
**<span style="color:#3182ce">Monitoring</span>** (while-listening): predictions 검증, 이해 여부 확인
**<span style="color:#3182ce">Evaluating</span>** (post-listening): 전체 이해도 점검

<span style="color:#c53030">⚠️ 함정</span>: Monitoring = while-listening(예측 검증), Evaluating = post-listening(이해도 점검). 시험에서 단계가 뒤바뀐 채 출제됨.

**<span style="color:#3182ce">Inferencing</span>**: listening between the lines — 불완전한 정보를 바탕으로 analyze, interpret, evaluate
**<span style="color:#3182ce">Scanning</span>**: 1~2가지 specific info 추출 (without understanding every word)
**<span style="color:#3182ce">Gist listening</span>**: topic only, global understanding
**<span style="color:#3182ce">Listening for detail</span>**: several pieces of detailed information, intensive
**<span style="color:#3182ce">Clarifying</span>**: 화자에게 질문·피드백 → 이해 향상. Interactive listening의 핵심. ("What does ___ mean?")
**<span style="color:#3182ce">Elaborating</span>**: prior knowledge를 활용해 텍스트 beyond로 나아가기

---

### Format of Listening Lesson — Pre / While / Post

**Pre-listening stage**:
- Motivating students:
  - **<span style="color:#3182ce">Signposting questions</span>**: T가 미리 제공 → 올바른 방향 안내 (T-provided)
  - **<span style="color:#3182ce">Generating questions</span>**: 제목을 받고 S가 최대한 많은 질문 생성 (S-created, learner-centered)
- **<span style="color:#3182ce">Pre-teaching critical vocabulary</span>**: 선별적 지도 + lexical chunks 포함. <span style="color:#c53030">All unknown words 전부 pre-teaching 금지</span>

**While-listening stage**:
1. **<span style="color:#3182ce">Extensive listening phase</span>** (1st play): general idea 파악 + predictions 확인
2. **<span style="color:#3182ce">Intensive listening phase</span>** (2nd play): pre-set Qs 제공 → specific info 파악

<span style="color:#c53030">⚠️ 순서 반전 함정</span>: Extensive → Intensive 순서. Intensive가 먼저가 아니다.

**Post-listening stage**:
- **<span style="color:#3182ce">Skill integration</span>**: 듣기 + speaking/writing/reading 통합 활동 (리스닝 한 번 더 듣는 것이 아님)
- **<span style="color:#3182ce">Reflection</span>**: 학습 내용 되돌아보기 + next listening 계획

---

### Listening Activities — Dictation / Dictogloss / Information Transfer / Jigsaw

> "Dictogloss: A collaborative outcome task where Ls work together to produce language forms and reproduce content collaboratively by reconstructing a text."

**<span style="color:#3182ce">Dictation</span>**: imitative writing activity → exact/accurate replica 생성. 의미와 무관, unnatural.
**<span style="color:#3182ce">Dictogloss</span>**: collaborative — 구두 제시 텍스트를 학습자들이 협력하여 재구성. bottom-up(세부 청취) + top-down(의미 재구성) 모두 활용.

**<span style="color:#3182ce">Information transfer</span>**: aural 정보 → visual representation으로 변환. Deep processing 촉진. (integrative activity)
**<span style="color:#3182ce">Jigsaw listening</span>**: information-gap principle 기반. 각 그룹이 서로 다른 내용을 듣고 정보 공유 → cooperative learning.

**<span style="color:#3182ce">Product-oriented listening</span>**: "Listen to learn" — 들은 내용을 다른 언어 활동에 활용
**<span style="color:#3182ce">Process-oriented listening</span>**: "Learn to listen" — 이해 과정(how) 자체에 초점, metacognitive awareness↑

**<span style="color:#3182ce">Metacognitive instruction</span>**: planning, monitoring, evaluating 전략 습득 촉진 → self-regulation↑

---

### Principles for Teaching Listening — Learner Level

> "To beginning Ls: Use a variety of tasks / Build on success / Do not teach strategies."

| 수준 | 지도 원칙 |
|------|----------|
| **Beginners** | variety of tasks, build on success, **NO strategy instruction** (cf. threshold hypothesis) |
| **Intermediate** | teach listening strategies, balance comprehension & acquisition |
| **Advanced** | teach culture, longer text structure 이해 강조 |

<span style="color:#c53030">⚠️ 함정</span>: Strategy instruction은 beginners가 아닌 **intermediate** 학습자부터.

---

### ETC — Back-channeling

**<span style="color:#3182ce">Back-channeling</span>**: 청자가 화자에게 경청하고 있음을 알려주는 신호.
- Verbal: yeah, um, ah, uh-huh
- Non-verbal: nodding, shrugging, facial gestures
<span style="color:#c53030">⚠️ "verbal만 해당"이라는 선지는 오답</span>

## ③ 키텀 비교

### Roughly-tuned vs Finely-tuned

| | Roughly-tuned | Finely-tuned |
|--|------|------|
| 특성 | 자연스러운 언어에 가까움 | 세심하게 통제됨 |
| 난이도 조절 | 대략적 (approximate) | 정밀하게 (carefully controlled) |
| 활용 | Authentic materials 맥락 | 문법 항목 제시 맥락 |

### Bottom-up vs Top-down vs Interactive

| | Bottom-up | Top-down | Interactive |
|--|------|------|------|
| 방향 | parts → whole | whole → parts | 양방향 |
| 초점 | linguistic form | prior knowledge, context | 통합 |
| 학습자 | beginners 적합 | advanced 적합 | level-differentiated 적합 |
| 전략 예시 | listening for detail | predicting, gist listening | — |

### Reactive vs Responsive vs Interactive

| | Reactive | Responsive | Interactive |
|--|------|------|------|
| 활동 | repeat back | appropriate response | give-and-take |
| T 역할 | — | T pushes output | — |

### Extensive vs Intensive

| | Extensive | Intensive |
|--|------|------|
| 텍스트 길이 | longer stretch | shorter |
| 목표 | general understanding | language analysis |
| Processing | top-down | bottom-up |

### Selective vs Intensive (vs Extensive)

| | Selective | Intensive |
|--|------|------|
| 텍스트 길이 | **longer** | shorter |
| 목적 | planned purpose, specific info | detailed analysis |
| 유사 개념 | scanning | — |

### Gist vs Scanning vs Listening for Detail

| | Gist | Scanning | Listening for Detail |
|--|------|------|------|
| 범위 | topic only | 1~2 specific info | several details |
| 강도 | light | targeted | intensive |

### Monitoring vs Evaluating

| | Monitoring | Evaluating |
|--|------|------|
| 단계 | while-listening | post-listening |
| 기능 | predictions 검증 | 전체 이해도 점검 |

### Dictation vs Dictogloss

| | Dictation | Dictogloss |
|--|------|------|
| 성격 | imitative | collaborative |
| 목표 | exact replica | reconstruct meaning |
| Processing | — | bottom-up + top-down |

### Product-oriented vs Process-oriented

| | Product-oriented | Process-oriented |
|--|------|------|
| 슬로건 | "Listen to learn" | "Learn to listen" |
| 초점 | what was comprehended | how understanding takes place |
| 결과물 | 다른 언어 활동 | metacognitive awareness↑ |

### Signposting Qs vs Generating Qs

| | Signposting Qs | Generating Qs |
|--|------|------|
| 출처 | T-provided | S-created |
| 방법 | 미리 제공 → 방향 안내 | 제목 받고 → 스스로 생성 |

## ④ 수험 팁

<span style="color:#dd6b20">**현직 쌤 팁 — 반전 함정 패턴 3종**</span>

Teaching Listening 문항은 개념 정의를 **뒤바꿔** 출제하는 패턴이 반복된다. 아래 세 쌍은 반드시 방향을 고정해 암기할 것:

1. **Roughly-tuned = natural/approximate ↔ Finely-tuned = carefully controlled** (정반대로 출제)
2. **Extensive phase 먼저 → Intensive phase 나중** (while-listening 순서)
3. **Beginners = NO strategies, Intermediate = strategies** (level 배분 반전)

<span style="color:#dd6b20">**답안 작성 패턴**</span>

기출 서술형 답안에서 Teaching Listening 개념은 다음 형식으로 쓴다:

- "X is a type of processing in which listeners ___."
- "Bottom-up processing focuses on decoding sounds in a linear fashion, moving from parts to whole, while top-down processing uses prior knowledge and context to reconstruct meaning."
- Strategy 설명: "[Strategy name] is a strategy in which learners ___, occurring at the [pre/while/post]-listening stage."

<span style="color:#dd6b20">**고빈도 연계 개념**</span>

- Predicting(pre) → Monitoring(while) → Evaluating(post): 세 metacognitive strategies를 **단계 순서대로** 한 세트로 암기
- Information transfer = aural → visual → deep processing 연결고리
- Jigsaw listening = information-gap principle + cooperative learning (두 개념 세트)
- Dictogloss = collaborative + bottom-up & top-down 동시 활용 (단독 개념이 아님)

<span style="color:#dd6b20">**Scaffolding 연결**</span>

Paused listening tasks는 단순 듣기 기법이 아니라 **scaffolding**의 구체적 예시로 설명된다. "scaffolding"이라는 키워드와 함께 묶어 서술할 것.
