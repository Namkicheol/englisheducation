# Ch.12 CALL · Material 완전 정리: Corpus부터 CAT, CMC, Material Evaluation까지

Ch.12는 다른 챕터처럼 이론가 이름을 길게 외우는 단원이라기보다, **digital tool이 어떤 learning condition을 만드는지**를 판단하는 단원이다. 같은 computer use라도 <span style="color:#3182ce">**drill and feedback**</span>인지, <span style="color:#3182ce">**collaboration**</span>인지, <span style="color:#3182ce">**authentic communication**</span>인지에 따라 답이 갈린다.

이 글은 CALL · Material에서 자주 묶이는 개념을 **① 개념 정의** → **② 기출 맥락** → **③ 헷갈리는 key terms** → **④ 답안 작성 패턴** 순서로 정리한다. 특히 <span style="color:#3182ce">**Corpus and Concordance**</span>, <span style="color:#3182ce">**CMC**</span>, <span style="color:#3182ce">**CAT**</span>, <span style="color:#3182ce">**CALL Approaches**</span>, <span style="color:#3182ce">**Material adaptation/evaluation**</span>은 label보다 **condition, learner role, evidence**를 먼저 잡아야 한다.

---

## ① 개념 정의 — tool보다 learner behavior를 먼저 본다

### 1) Corpus, Concordancer, KWIC

> Corpus linguistics studies language through large, principled collections of authentic texts. A concordancer searches a corpus and displays the occurrences of a keyword in context, often in KWIC format.

<span style="color:#3182ce">**Corpus linguistics**</span>는 corpus라는 large collection of sampled authentic texts를 대상으로 language use를 살펴보는 영역이다. 시험에서는 corpus 자체의 정의보다 **computer가 어떤 evidence를 보여 주는가**가 중요하다.

| 핵심어 | 시험에서 보는 지점 |
|---|---|
| <span style="color:#3182ce">**Corpus**</span> | sampled authentic texts의 large collection |
| <span style="color:#3182ce">**Concordancer**</span> | keyword나 expression이 나타난 context를 배열해 주는 software |
| <span style="color:#3182ce">**Concordance**</span> | 검색 결과로 제시되는 usage examples |
| <span style="color:#3182ce">**KWIC**</span> | keyword in context format. target item이 중앙에 오고 전후 context가 보임 |

예를 들어 learner가 `make`와 `do`의 concordance lines를 보고 뒤에 오는 nouns를 비교한다면, 답안의 초점은 "computer를 사용했다"가 아니라 **actual usage pattern을 비교하게 했다**는 점이다.

> 💡 <span style="color:#dd6b20">**현직쌤 팁**</span>: concordancer 문항은 `keyword`, `context`, `pattern`, `frequency`, `actual use` 중 하나가 evidence로 나온다. 답안에는 "The concordancer helps learners notice patterns in authentic language data"처럼 mechanism을 써 주면 안정적이다.

---

### 2) Data-driven Learning — rule presentation이 아니라 rule discovery

> Data-driven learning uses computer-generated concordances to help learners explore regularities in the target language and formulate rules inductively.

<span style="color:#3182ce">**Data-driven learning**</span>은 learner가 concordance result를 보며 target expression의 regularities를 탐색하고, 그 결과를 바탕으로 rule을 <span style="color:#3182ce">**inductively**</span> 형성하는 학습이다.

핵심 흐름은 다음과 같다.

1. Learner가 concordance lines를 본다.
2. Target word 앞뒤의 context를 비교한다.
3. 반복되는 form-meaning pattern을 찾는다.
4. Rule을 스스로 formulate한다.
5. Teacher는 정답을 먼저 말하기보다 search, compare, revise를 안내한다.

따라서 Data-driven learning은 <span style="color:#c53030">teacher가 grammar rule을 먼저 설명하고 learner가 예문에 적용하는 방식이 아니다</span>. 이 함정이 OX와 서술형에서 자주 나온다.

---

### 3) CMC — synchronous / asynchronous 조건으로 자른다

<span style="color:#3182ce">**CMC (computer-mediated communication)**</span>는 computer를 매개로 한 communication이다. 임용에서는 거의 항상 <span style="color:#3182ce">**synchronous CMC**</span>와 <span style="color:#3182ce">**asynchronous CMC**</span>의 condition 차이를 묻는다.

| | <span style="color:#3182ce">**Synchronous CMC**</span> | <span style="color:#3182ce">**Asynchronous CMC**</span> |
|---|---|---|
| 시간 조건 | participants가 동시에 online | 각자 편한 시간에 access |
| 예시 | chat, text-based conferencing, audio/video conferencing, MOOs | e-mail, bulletin board system, mailing lists |
| 강점 | 즉각적 interaction, negotiation of meaning, peer response | reflection time, process-oriented writing feedback, culture learning |
| 약점 | schedule/time-zone constraint, editing time 부족 | immediate response나 live negotiation은 약함 |

Chat은 real-time이라 learner가 comprehension check, clarification request, confirmation check를 바로 사용할 수 있다. 반면 e-mail이나 bulletin board system은 즉각성은 낮지만, learner가 message를 revise하고 longer response를 만들 시간이 있다.

---

### 4) E-learning 계열 — 이름보다 delivery condition

<span style="color:#3182ce">**E-learning**</span>은 technology-based learning 전체를 가리키지만, 시험에서는 아래 네 용어를 섞어 낸다.

| 용어 | 핵심 조건 |
|---|---|
| <span style="color:#3182ce">**Distance learning**</span> | technology를 통해 떨어진 공간에서 learning이 이루어짐 |
| <span style="color:#3182ce">**Online learning**</span> | Internet을 통해 learning이 이루어짐 |
| <span style="color:#3182ce">**Open learning**</span> | learner autonomy와 access flexibility가 핵심 |
| <span style="color:#3182ce">**Blended learning**</span> | online course delivery와 face-to-face course delivery의 mixture |

<span style="color:#c53030">**함정**</span>: Blended learning은 "online 수업" 하나로 끝나지 않는다. 반드시 face-to-face component와 online component가 함께 있어야 한다.

---

### 5) CAT — item sequence가 learner performance에 따라 변한다

> Computer-adaptive testing selects subsequent items based on the test-taker's performance on preceding items.

<span style="color:#3182ce">**CAT (computer-adaptive testing)**</span>는 test-taker가 앞 item에서 보인 performance에 따라 다음 item difficulty가 조정되는 testing이다. 같은 test라도 모든 learner가 같은 item sequence를 받는 것이 아니다.

장점:

- Individual proficiency를 비교적 빠르게 추정할 수 있다.
- Learner current level에 맞는 item을 제공한다.
- Item bank와 ability estimation이 결합될 때 효율적이다.

주의점:

- Open-ended questions를 다루기 어렵다.
- Item bank quality가 낮으면 test result도 흔들린다.
- <span style="color:#3182ce">**construct validity**</span> 문제가 생길 수 있다.

<span style="color:#c53030">**2023 A-4**</span>는 `computer adaptive testing (CAT)`, `item response theory (IRT)`, `item bank`, `ability estimation`이 함께 잡힌 문항으로 정리되어 있다.

---

### 6) CALL Approaches — Behavioristic vs Constructivist

<span style="color:#3182ce">**CALL Approaches**</span>는 computer의 존재 여부가 아니라 **computer가 어떤 learning role을 맡는가**로 구분한다.

| | <span style="color:#3182ce">**Behavioristic CALL**</span> | <span style="color:#3182ce">**Constructivist CALL**</span> |
|---|---|---|
| Computer 역할 | drills, practice, tutorial explanation, corrective feedback 제공 | authentic materials, communication opportunities, inquiry space 제공 |
| Learner 역할 | own pace로 programmed instruction 수행 | exploration, collaboration, inquiry-based learning |
| 전형적 장면 | grammar/vocabulary drill, immediate right/wrong feedback | virtual environment, project, collaborative problem solving |
| 판단 기준 | accuracy practice 중심 | meaning-making and collaboration 중심 |

<span style="color:#c53030">**2024 A-12**</span>는 `CALL`, `virtual environment`, `collaborative learning`이 핵심 프레임으로 정리되어 있다. 따라서 단순히 "digital tool 사용"이 아니라 learner가 virtual environment 안에서 협력적으로 task를 수행하는지 봐야 한다.

---

### 7) Material — adaptation과 evaluation을 분리한다

<span style="color:#3182ce">**Authentic materials**</span>는 real-life language exposure를 제공해 learner가 실제 language use strategy를 발달시키도록 돕는다. 다만 authentic이면 무조건 좋은 것이 아니라, learner level과 objective에 맞게 조정되어야 한다.

<span style="color:#3182ce">**Material adaptation**</span>은 learner level, objective, context에 맞게 content, task, sequence를 조정하는 과정이다. 단순히 easy version으로 바꾸는 것이 아니라, **무엇을 더하고, 빼고, 바꾸는가**를 수업 목표와 연결해야 한다.

<span style="color:#3182ce">**Material evaluation**</span>은 material을 선택하거나 판단할 때 쓰는 기준이다.

- Objectives
- Learner needs
- Skill balance
- Authenticity
- Practicality
- Evaluation criteria

<span style="color:#c53030">**2023 A-8**</span>은 `needs analysis`, `material adaptation`, `tap into students' lives`가 함께 정리되어 있다. Material 문항에서 needs analysis 결과가 주어지면, 답안은 "학생에게 맞췄다"가 아니라 **what was adapted and why**로 써야 한다.

---

## ② 기출 맥락 — 확인된 evidence만 사용

Ch.12는 해마다 CALL 단독으로만 나오는 것이 아니라 assessment, vocabulary, material, peer feedback, culture learning과 연결되어 출제된다. 확인된 맥락은 다음처럼 정리할 수 있다.

### 자주 잡히는 출제 포인트

- <span style="color:#c53030">**2023 A-4**</span>: <span style="color:#3182ce">**CAT**</span>, <span style="color:#3182ce">**IRT**</span>, <span style="color:#3182ce">**item bank**</span>, <span style="color:#3182ce">**ability estimation**</span>
- <span style="color:#c53030">**2023 B-10**</span>: <span style="color:#3182ce">**collocation**</span>, <span style="color:#3182ce">**grammar (lexical aspect)**</span>, <span style="color:#3182ce">**concordancer**</span>
- <span style="color:#c53030">**2023 A-8**</span>: <span style="color:#3182ce">**needs analysis**</span>, <span style="color:#3182ce">**material adaptation**</span>, student relevance
- <span style="color:#c53030">**2024 A-12**</span>: <span style="color:#3182ce">**CALL**</span>, <span style="color:#3182ce">**virtual environment**</span>, <span style="color:#3182ce">**collaborative learning**</span>
- <span style="color:#c53030">**2026 B-5**</span>: <span style="color:#3182ce">**CALL**</span>, <span style="color:#3182ce">**peer feedback**</span>, <span style="color:#3182ce">**fluency**</span>

### 답안이 요구하는 사고 순서

CALL · Material 문항은 보통 다음 순서로 풀면 흔들리지 않는다.

```
1. Tool or material이 무엇인가?
2. 그 tool/material이 만드는 condition은 무엇인가?
3. Learner가 실제로 무엇을 하는가?
4. 그 action이 어떤 learning/assessment purpose와 연결되는가?
```

예를 들어 "students compare concordance lines for collocations"라는 장면이면, 답은 Corpus and Concordance 또는 Data-driven learning 쪽으로 간다. 반대로 "students exchange drafts and comments through a digital product"라면 CALL product, peer feedback, fluency 또는 writing process 쪽으로 읽어야 한다.

## ③ 헷갈리는 key terms 비교

### Corpus and Concordance vs Data-driven Learning

| | Corpus and Concordance | Data-driven Learning |
|---|---|---|
| 초점 | tool/data | learning procedure |
| 핵심 증거 | corpus, concordancer, KWIC, keyword in context | learner compares examples and formulates rules |
| 답안 동사 | displays, arrays, shows | discovers, compares, induces, formulates |
| 함정 | corpus를 그냥 "online text"로 보기 | teacher-led grammar explanation으로 착각 |

둘은 함께 나오지만 같지는 않다. Concordancer는 tool이고, Data-driven learning은 그 tool을 활용해 learner가 inductive rule discovery를 하는 approach다.

---

### Synchronous CMC vs Asynchronous CMC

| | Synchronous CMC | Asynchronous CMC |
|---|---|---|
| 핵심 조건 | same time | different times possible |
| interaction | 즉각적 response | delayed response |
| 좋은 evidence | chat, real-time conferencing, MOO | e-mail, bulletin board system, mailing list |
| 답안 초점 | negotiation, immediate feedback | reflection, revision, process feedback |

<span style="color:#c53030">**함정**</span>: "computer로 소통했다"만 보고 CMC라고 쓰면 부족하다. synchronous인지 asynchronous인지, 그 condition이 어떤 learning effect를 만드는지까지 써야 한다.

---

### CAT vs 일반 computer-based test

| | CAT | 일반 computer-based test |
|---|---|---|
| item sequence | performance에 따라 조정 | 미리 정해진 sequence 가능 |
| 핵심 장치 | item bank, ability estimation | delivery medium이 computer |
| 판단 기준 | 다음 item difficulty가 바뀌는가 | 단순히 computer screen에서 푸는가 |

Computer-based test라고 해서 자동으로 CAT가 아니다. <span style="color:#3182ce">**adaptive**</span>라는 말은 item selection이 test-taker performance에 반응한다는 뜻이다.

---

### Behavioristic CALL vs Constructivist CALL

| | Behavioristic CALL | Constructivist CALL |
|---|---|---|
| 학습관 | programmed practice | learner-constructed knowledge |
| feedback | right/wrong corrective feedback 중심 | peer/teacher interaction 속 meaning negotiation 가능 |
| material | controlled items | authentic resources |
| 장면 | fill-in drill, tutorial, repeated practice | virtual project, collaborative task, authentic communication |

OX 선지에서 "computer provides immediate corrective feedback"이 나오면 Behavioristic CALL 쪽이다. "learners explore resources and collaborate to solve a problem"이면 Constructivist CALL 쪽이다.

---

### Material adaptation vs Material evaluation

| | Material adaptation | Material evaluation |
|---|---|---|
| 질문 | 어떻게 바꾸는가? | 어떤 기준으로 판단하는가? |
| evidence | adding, deleting, modifying, sequencing | objectives, learner needs, authenticity, practicality |
| 답안 | The teacher adapts the material by ... | The material is appropriate because ... |

Material 문항은 "자료가 좋다/나쁘다"로 쓰면 약하다. 반드시 criterion을 붙여야 한다.

## ④ 합격자 노트식 답안 작성 패턴

### 패턴 1: CALL tool 선택 근거

```
The teacher chooses [tool] because it enables learners to [learner action].
This supports [purpose] by providing [condition/evidence].
```

예시:

```
The teacher uses a concordancer because it enables learners to compare authentic examples of the target expression.
This supports data-driven learning by helping learners notice recurring patterns and formulate rules inductively.
```

---

### 패턴 2: CMC 구분

```
The activity uses [synchronous/asynchronous] CMC because learners [time condition].
This condition helps them [interaction effect].
```

예시:

```
The activity uses synchronous CMC because learners interact in real time through chat.
This condition promotes immediate negotiation of meaning and peer response.
```

---

### 패턴 3: Material adaptation 근거

```
The teacher adapts the material by [adding/deleting/modifying X].
This adaptation matches [learner need/objective/context] because [specific evidence].
```

예시:

```
The teacher adapts the material by adding topics from students' daily lives.
This adaptation matches learner needs because it taps into students' lives and makes the task more personally relevant.
```

---

### 패턴 4: CAT 판별

```
The test is computer-adaptive because the next item is selected based on the test-taker's previous performance.
This helps estimate the learner's ability more efficiently than a fixed item sequence.
```

## ⑤ 실전 함정 정리

### 함정 1: "computer 사용"만 보고 CALL approach를 결정

CALL 문항의 핵심은 computer 자체가 아니다. Computer가 drill machine인지, communication channel인지, authentic resource access인지가 답을 가른다.

### 함정 2: Concordancer와 Data-driven Learning을 같은 말로 처리

Concordancer는 tool이고, Data-driven learning은 learner가 그 tool을 통해 pattern을 inductively discover하는 procedure다. 답안에서 둘을 구분하면 점수가 안정된다.

### 함정 3: Synchronous CMC를 "빠른 e-mail"처럼 이해

Synchronous CMC는 동시에 online 상태에서 real-time response가 가능해야 한다. E-mail은 빠르게 답장을 해도 기본적으로 asynchronous CMC다.

### 함정 4: CAT를 computer-based test와 혼동

CAT는 item selection이 adaptive해야 한다. 단순히 computer에서 시험을 보는 것은 CAT의 충분조건이 아니다.

### 함정 5: Material evaluation을 감상평처럼 쓰기

"good material"이라고 쓰지 말고, objectives, learner needs, skill balance, authenticity, practicality, evaluation criteria 중 하나를 evidence와 연결해야 한다.

> 💡 <span style="color:#dd6b20">**현직쌤 팁**</span>: Ch.12 답안은 "정의 암기"보다 "근거 붙이기"가 중요하다. `because it enables learners to...`, `by providing...`, `based on...` 세 표현만 잘 써도 답안이 훨씬 시험형으로 정리된다.
