# Ch.12 CALL · Material — CALL과 Material 핵심 정리 | 임용영어 개념 정리

---

## ① 개념 정의

### Corpus, Concordancer, KWIC — CALL의 data 기반 도구

<span style="color:#3182ce">**Corpus linguistics**</span>는 corpus라는 large collection of sampled authentic texts를 대상으로 language를 살펴보는 영역이다. CALL 문항에서는 corpus 자체보다, learner가 corpus를 **어떻게 읽고 어떤 pattern을 찾는지**가 더 중요하다.

| 핵심어 | 확인 포인트 |
|---|---|
| <span style="color:#3182ce">**Corpus**</span> | sampled authentic texts의 large collection |
| <span style="color:#3182ce">**Concordancer**</span> | keyword가 나타난 context를 배열해 보여 주는 program |
| <span style="color:#3182ce">**KWIC**</span> | keyword in context format으로 concordance result를 확인 |

<span style="color:#c53030">**2024 A-12**</span> — CALL과 digital tool 선택 근거 맥락

---

### Data-driven Learning — pattern을 보고 rule을 만드는 학습

<span style="color:#3182ce">**Data-driven learning**</span>은 learner가 target word 사용을 비교하고 pattern regularity를 탐색해 **inductively rule**을 형성하는 학습이다.

핵심 흐름:
1. Concordance result 확인
2. 비슷한 usage pattern 비교
3. Regularity 탐색
4. Learner가 rule을 inductively 형성

<span style="color:#c53030">**⚠️ 함정**: Data-driven learning은 teacher가 rule을 먼저 제시하고 learner가 적용하는 방식이 아니다. Corpus data를 보며 learner가 pattern을 찾아간다는 점이 핵심이다.</span>

---

## ② 기출 맥락

### CMC — synchronous vs asynchronous 구분

<span style="color:#3182ce">**CMC**</span>는 computer-mediated communication이다. 임용에서는 synchronous / asynchronous 구분이 먼저다.

| | <span style="color:#3182ce">**Synchronous CMC**</span> | <span style="color:#3182ce">**Asynchronous CMC**</span> |
|---|---|---|
| 시간 조건 | participants가 동시에 log on | 시간차 communication 가능 |
| 예시 | chat, text-based conferencing, audio/video conferencing, MOOs | e-mail, bulletin board system |
| 활용 | 즉각적 interaction, peer feedback | culture learning, collaborative problem solving, process-oriented writing feedback |

<span style="color:#c53030">**2026 B-5**</span> — CALL product와 peer feedback 맥락

---

### CALL Approaches — behavioristic vs constructivist

<span style="color:#3182ce">**Behavioristic CALL**</span>과 <span style="color:#3182ce">**Constructivist CALL**</span>은 tool의 기능보다 learner role을 기준으로 구분한다.

| | <span style="color:#3182ce">**Behavioristic CALL**</span> | <span style="color:#3182ce">**Constructivist CALL**</span> |
|---|---|---|
| Computer 역할 | drills, practice, tutorial explanation, corrective feedback 제공 | authentic materials와 communication opportunities 제공 |
| Learner 역할 | own pace로 programmed instruction 수행 | exploration, collaboration, inquiry-based learning |
| 학습관 | 반복 practice 중심 | learner가 knowledge를 구성 |

<span style="color:#c53030">**2024 A-12**</span> — virtual environment와 collaborative learning 맥락

---

## ③ 키텀 비교

### E-learning 계열 — online, distance, open, blended

<span style="color:#3182ce">**E-learning**</span>에서는 이름이 비슷한 네 용어를 조건으로 나눠야 한다.

| 용어 | 핵심 조건 |
|---|---|
| <span style="color:#3182ce">**Distance learning**</span> | technology를 통한 learning |
| <span style="color:#3182ce">**Online learning**</span> | Internet을 통해 이루어지는 learning |
| <span style="color:#3182ce">**Open learning**</span> | learner autonomy의 정도와 관련 |
| <span style="color:#3182ce">**Blended learning**</span> | online과 face-to-face course delivery의 mixture |

<span style="color:#c53030">**⚠️ 함정**: Blended learning은 online만 뜻하지 않는다. Online course delivery와 face-to-face course delivery의 mixture라는 점을 확인한다.</span>

---

### CAT — item이 performance에 맞게 조정되는 test

<span style="color:#3182ce">**CAT**</span>는 computer-adaptive testing이다. 이전 item performance를 바탕으로 다음 item이 test-taker current level에 맞게 조정된다.

장점:
- Individual proficiency를 비교적 빠르게 파악
- Test-taker level에 맞는 item 제공

주의점:
- Open-ended questions 활용이 어려움
- <span style="color:#c53030">**construct validity**</span> 문제가 생길 수 있음

---

## ④ Material

### Authentic Materials와 Material Adaptation

<span style="color:#3182ce">**Authentic materials**</span>는 real-life language exposure를 제공해 learner가 실제 language use strategy를 발달시키도록 돕는다.

<span style="color:#3182ce">**Material adaptation**</span>은 learner level, objective, context에 맞게 content, task, sequence를 조정하는 과정이다. 단순히 자료를 쉽게 바꾸는 것이 아니라, 수업 목적과 learner needs에 맞게 task condition을 재설계하는 쪽에 가깝다.

---

### Material Evaluation — 기준을 명확히 두고 선택

<span style="color:#3182ce">**Material evaluation**</span>은 다음 기준으로 이루어질 수 있다.

- Objectives
- Learner needs
- Skill balance
- Authenticity
- Practicality
- Evaluation criteria

Evaluation criteria나 scoring rubric이 명확해야 material selection과 assessment가 연결된다.

<span style="color:#dd6b20">**현직쌤 팁**: Ch.12는 용어 암기보다 “tool이 무엇을 가능하게 하는가”, “learner가 어떤 역할을 하는가”, “task condition이 어떻게 달라지는가”를 기준으로 보면 선지가 빨리 정리된다.</span>

## ⑤ 수험 활용 팁

### OX 선지 판단 기준

CALL · Material 문항은 용어를 비슷하게 섞어 내기 쉽다. 아래 세 질문으로 선지를 자르면 안정적이다.

1. 이 개념의 **condition**은 무엇인가?
   예: synchronous는 동시에 log on, asynchronous는 시간차 communication.

2. Learner는 무엇을 하는가?
   예: Data-driven learning은 learner가 pattern을 비교하고 inductively rule을 형성.

3. Tool은 무엇을 제공하는가?
   예: Behavioristic CALL은 drills, practice, tutorial explanation, corrective feedback 제공.
