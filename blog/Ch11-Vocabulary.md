# Ch.11 Teaching Vocabulary — vocabulary 지도 완전 정복 | 임용영어 개념 정리

---

## ① 개념 정의

### Word Knowledge — 무엇을 안다는 것인가

<span style="color:#3182ce">**Word knowledge**</span>는 단어의 뜻만 아는 것이 아니다. 임용에서는 vocabulary를 얼마나 넓게 알고 있는지와 얼마나 깊게 알고 있는지를 함께 묻는다.

| 요소 | 확인 포인트 |
|---|---|
| frequency | 얼마나 자주 쓰이는 word인가 |
| collocation | 어떤 words와 함께 나타나는가 |
| register | 어떤 상황·집단·맥락에서 쓰이는가 |
| word family | base form, inflection, derivation 관계 |
| word association | 어떤 words와 연결되는가 |
| semantic feature | meaning 차이를 구분하는 feature |

<span style="color:#c53030">**2019 기입10**</span> — word knowledge, depth, breadth 맥락

<span style="color:#c53030">**⚠️ 함정**: Word knowledge를 단순히 "뜻 암기"로 좁히면 오답이 되기 쉽다. collocation, register, word family까지 함께 보아야 한다.</span>

---

### Syntagmatic vs Paradigmatic Relationship

Vocabulary 관계를 볼 때는 두 축을 구분한다.

- <span style="color:#3182ce">**Syntagmatic relationship**</span>: sentence 안에서 함께 배열되는 horizontal relation. collocation처럼 어떤 words가 함께 쓰이는지 확인한다.
- <span style="color:#3182ce">**Paradigmatic relationship**</span>: 같은 위치에서 선택 가능한 lexical alternatives. synonym, antonym, hyponym 등이 여기에 들어간다.

예를 들어 *make a decision*에서 *make*와 *decision*의 결합은 syntagmatic relationship이다. 반면 *big / large / huge*처럼 선택 가능한 words의 관계는 paradigmatic relationship으로 본다.

## ② 기출 맥락

### Explicit Learning vs Implicit Learning

Vocabulary learning은 학습자의 attention이 vocabulary에 직접 향하는지에 따라 구분한다.

| | <span style="color:#3182ce">**Explicit learning of vocabulary**</span> | <span style="color:#3182ce">**Implicit learning of vocabulary**</span> |
|---|---|---|
| attention | overt attention to vocabulary | meaningful text 처리 중 incidental |
| 지식 성격 | declarative knowledge 발달 | repeated exposure를 통한 점진적 습득 |
| 대표 활동 | deliberate learning, dictionary work, semantic elaboration, mnemonic devices | extensive reading/listening, graded readers, SSR |
| 적합 맥락 | beginner, reading class, 핵심 vocabulary 지도 | 충분한 input과 반복 노출 |

<span style="color:#c53030">**2020 논술2**</span> — explicit teaching과 incidental learning 비교 맥락
<span style="color:#c53030">**2012 Q29**</span> — vocabulary teaching과 incidental learning 맥락

<span style="color:#c53030">**⚠️ 함정**: Explicit learning은 vocabulary 자체에 주의를 집중시킨다. Implicit learning은 vocabulary를 배우려는 직접 의도 없이 meaningful text를 처리하는 중에 일어난다.</span>

---

### High-frequency Words vs Low-frequency Words

<span style="color:#3182ce">**High-frequency words**</span>는 많이 쓰이므로 수업에서 시간을 들여 다룰 가치가 크다. meaning-focused input, meaning-focused output, deliberate learning, fluency development를 통해 반복적으로 만나게 한다.

<span style="color:#3182ce">**Low-frequency words**</span>는 모든 word를 직접 가르치기보다 처리 전략을 길러 주는 방향이 중요하다. part of speech, word parts, immediate collocation, word association, wider textual context를 활용해 meaning을 추론하게 한다.

| | High-frequency words | Low-frequency words |
|---|---|---|
| 지도 초점 | 자주 만나고 정확히 쓰게 하기 | word learning strategies |
| 수업 처리 | deliberate learning 가능 | 빠르게 처리하거나 strategy로 전환 |
| 연결 개념 | fluency development | guessing strategies |

## ③ 키텀 비교

### Keyword Method — mnemonic device

<span style="color:#3182ce">**Keyword method**</span>는 L1에서 phonologically familiar word를 찾고, target word meaning과 연결되는 visual image를 만드는 mnemonic device이다.

절차는 보통 다음처럼 정리할 수 있다.

1. Target word와 sound가 비슷한 familiar word를 찾는다.
2. Familiar word와 target meaning을 연결하는 image를 만든다.
3. Image를 통해 target word meaning을 recall한다.

Keyword method는 <span style="color:#3182ce">**depth of processing**</span>과 연결된다. 단순 반복보다 더 깊은 mental processing을 요구하므로 retention에 유리하다.

<span style="color:#c53030">**⚠️ 함정**: Keyword method는 아무 word나 무작정 반복하는 방식이 아니다. sound link와 image link가 함께 작동해야 한다.</span>

---

### Semantic Mapping — visual network

<span style="color:#3182ce">**Semantic mapping**</span>은 thematically related words의 relationship을 visual network로 구성하는 technique이다.

수업에서는 보통 중심 topic을 놓고 learner가 이미 아는 words를 retrieve한 뒤, related words를 category별로 연결한다. 이 과정에서 learner는 vocabulary를 isolated list가 아니라 associative network로 정리한다.

| Semantic Mapping 핵심 | 설명 |
|---|---|
| retrieve | learner가 이미 아는 words를 꺼냄 |
| organize | related words를 category로 묶음 |
| visualize | 관계를 map 형태로 봄 |
| expand | 새 vocabulary를 기존 network에 연결 |

---

### Collocation vs Lexical Phrases

<span style="color:#3182ce">**Collocation**</span>은 two or more words가 discourse에서 함께 나타나는 경향이다. matching activity와 gap-filling activity로 지도할 수 있으며, advanced learner에게 특히 중요하다.

<span style="color:#3182ce">**Lexical phrases**</span>는 frequent use로 conventionalized된 recurring phrases or patterns이다. lexical chunks, prefabricated routines, routine formulae, gambits와 연결되며 fluency와 pragmatic competence 발달에 도움이 된다.

<span style="color:#c53030">**2013 Q28**</span> — collocation과 lexical chunk 교수 맥락
<span style="color:#c53030">**2014 기입15**</span> — lexical approach와 chunks 맥락

| | Collocation | Lexical Phrases |
|---|---|---|
| 중심 | words가 함께 나타나는 경향 | 반복적으로 굳어진 phrase/pattern |
| 예시 판단 | word combination | prefabricated routine, gambit |
| 수험 포인트 | 함께 쓰이는 words | chunk 단위 처리와 fluency |

## ④ 수험 활용 팁

### Vocabulary Growth — noticing, retrieval, elaboration

L2 vocabulary growth activity에는 세 요소가 중요하다.

- <span style="color:#3182ce">**Noticing**</span>: useful language item을 awareness로 끌어올림
- <span style="color:#3182ce">**Retrieval**</span>: receptive/productive retrieval을 통해 다시 꺼내 봄
- <span style="color:#3182ce">**Elaboration**</span>: word를 더 많은 association과 context에 연결함

답안 작성에서는 "activity가 vocabulary growth에 도움이 된다"라고만 쓰지 말고, 어떤 요소를 작동시키는지 붙이면 안정적이다.

예시 패턴:

> This activity promotes vocabulary growth because it requires learners to notice useful vocabulary items, retrieve them repeatedly, and elaborate them by connecting them with related words or contexts.

---

### 실전 판단 순서

Vocabulary 문항은 label만 외우기보다 condition 확인이 중요하다.

1. 문제 상황이 vocabulary에 overt attention을 요구하는가? → explicit learning 가능성
2. Meaningful text 처리 중 자연스럽게 노출되는가? → implicit/incidental learning 가능성
3. Word combination을 묻는가? → collocation
4. Conventionalized phrase나 chunk를 묻는가? → lexical phrases
5. Visual network를 만드는가? → semantic mapping
6. Sound link와 image link를 쓰는가? → keyword method

<span style="color:#dd6b20">**현직쌤 팁**: Teaching Vocabulary는 용어가 쉬워 보여도 선지가 "뜻을 안다" 수준으로 축소하거나, collocation과 lexical phrase를 섞는 방식으로 함정을 만든다. 정의 속 condition을 먼저 체크하자.</span>
