# Ch.11 Teaching Vocabulary — vocabulary 지도 완전 정복 | 임용영어 개념 정리

Teaching Vocabulary는 용어 자체는 쉬워 보이지만, 실제 문항에서는 **"무엇을 아는가"**, **"어떤 attention이 작동하는가"**, **"word 단위인가 chunk 단위인가"**를 집요하게 묻는다. 단순히 "vocabulary를 가르친다"라고 쓰면 답안이 흐려지고, activity가 어떤 mechanism을 작동시키는지 써야 점수가 안정된다.

이 글은 Ch.11의 핵심을 **Word knowledge**, **vocabulary learning 유형**, **frequency 기준 지도**, **classroom techniques**, **multi-word units**, **답안 작성 패턴** 중심으로 정리한다.

---

## ① 개념 정의 — Word knowledge는 "뜻 암기"가 아니다

### Word Knowledge — breadth와 depth

<span style="color:#3182ce">**Word knowledge**</span>는 learner가 word의 meaning만 아는 상태가 아니다. 임용에서는 특히 <span style="color:#3182ce">**vocabulary breadth**</span>와 <span style="color:#3182ce">**vocabulary depth**</span>를 구분한다.

| 구분 | 핵심 | 답안에서 잡을 단서 |
|---|---|---|
| <span style="color:#3182ce">**vocabulary breadth**</span> | learner가 아는 words의 수 | "how many words", "size" |
| <span style="color:#3182ce">**vocabulary depth**</span> | 각 word를 얼마나 질적으로 깊게 아는가 | collocation, register, word family, association |

예를 들어 learner가 *make*의 뜻을 "만들다"로만 알면 breadth에는 포함될 수 있지만 depth는 약하다. *make a decision*, *make an effort*, *make a mistake*처럼 <span style="color:#3182ce">**collocation**</span>을 알고, *decision / decide / decisive*의 <span style="color:#3182ce">**word family**</span>를 연결하며, formal/informal <span style="color:#3182ce">**register**</span>를 구분할 때 word knowledge가 깊어진다.

<span style="color:#c53030">**2019 기입10**</span> — word knowledge, depth, breadth 맥락

> 💡 <span style="color:#dd6b20;">**현직쌤 팁**</span>: 답안에서 "students know the meaning"만 쓰면 얕다. "the activity elaborates word knowledge by connecting the target word with its collocations, word family, and register"처럼 **depth의 구성 요소**를 붙여야 한다.

### Components of Word Knowledge

| 요소 | 확인 포인트 |
|---|---|
| <span style="color:#3182ce">**frequency**</span> | 얼마나 자주 쓰이는 word인가 |
| <span style="color:#3182ce">**collocation**</span> | 어떤 words와 함께 나타나는가 |
| <span style="color:#3182ce">**register**</span> | 어떤 상황·집단·맥락에서 쓰이는가 |
| <span style="color:#3182ce">**word family**</span> | base form, inflection, derivation 관계 |
| <span style="color:#3182ce">**word association**</span> | 어떤 words와 연결되는가 |
| <span style="color:#3182ce">**semantic feature**</span> | meaning 차이를 가르는 feature |

<span style="color:#c53030">**⚠️ 함정**</span>: Word knowledge를 "definition을 말할 수 있음"으로 축소하면 오답이 되기 쉽다. 특히 collocation이나 register 단서가 나오면 vocabulary depth를 묻는 경우가 많다.

## ② Syntagmatic vs Paradigmatic Relationship

Vocabulary relationship은 두 축으로 나뉜다. 이 구분은 collocation과 synonym/antonym 판단에서 자주 흔들린다.

| | <span style="color:#3182ce">**Syntagmatic relationship**</span> | <span style="color:#3182ce">**Paradigmatic relationship**</span> |
|---|---|---|
| 방향 | sentence 안에서 함께 배열되는 horizontal relation | 같은 자리에서 선택 가능한 lexical alternatives |
| 대표 단서 | collocation, co-occurrence | synonym, antonym, hyponym |
| 예시 | *commit a crime*, *strong tea* | *big / large / huge* |
| 답안 포인트 | "words typically occur together" | "words can substitute/contrast in the same slot" |

예를 들어 *strong tea*에서 *strong*과 *tea*가 함께 나타나는 경향은 syntagmatic relationship이다. 반면 *strong / weak*처럼 같은 위치에서 대립 가능한 choices는 paradigmatic relationship이다.

> 💡 <span style="color:#dd6b20;">**현직쌤 팁**</span>: collocation이 보이면 syntagmatic으로 바로 연결하자. synonym, antonym, hyponym이 보이면 paradigmatic이다. 둘 다 "related words"라고 뭉개 쓰면 채점 포인트가 사라진다.

## ③ Vocabulary Learning — Explicit vs Implicit

### Explicit Learning of Vocabulary

<span style="color:#3182ce">**Explicit learning of vocabulary**</span>는 learner의 overt attention이 vocabulary itself에 직접 향한다. Teacher가 target words를 제시하고, learner가 meaning, form, word parts, collocation, word family를 의식적으로 처리한다.

대표 활동은 deliberate learning, dictionary work, semantic elaboration, mnemonic devices, input enhancement, word association activities이다. 초기 단계 learner나 high-frequency words처럼 수업에서 직접 다룰 가치가 큰 vocabulary에 특히 유용하다.

### Implicit / Incidental Vocabulary Learning

<span style="color:#3182ce">**Implicit learning of vocabulary**</span> 또는 <span style="color:#3182ce">**incidental vocabulary learning**</span>은 learner의 attention이 vocabulary learning 자체가 아니라 text 이해나 communication에 있을 때 일어난다. Extensive reading/listening, graded readers, SSR 같은 활동에서 repeated exposure가 쌓이며 vocabulary가 점진적으로 발달한다.

| | <span style="color:#3182ce">**Explicit learning**</span> | <span style="color:#3182ce">**Implicit / incidental learning**</span> |
|---|---|---|
| attention | vocabulary에 overt attention | meaning/text/communication에 attention |
| 지식 성격 | declarative knowledge 강화 | repeated exposure를 통한 점진적 learning |
| 활동 | dictionary work, mnemonic devices, semantic mapping | extensive reading/listening, graded readers, SSR |
| 적합 상황 | beginner, 핵심 high-frequency words | proficiency가 어느 정도 있고 input 양이 충분할 때 |

<span style="color:#c53030">**2020 논술2**</span> — explicit teaching과 incidental learning 비교 맥락
<span style="color:#c53030">**2012 Q29**</span> — vocabulary teaching과 incidental learning 맥락

<span style="color:#c53030">**⚠️ 함정**</span>: "text를 읽으면서 word를 배웠다"가 항상 implicit은 아니다. Teacher가 target words에 밑줄을 긋고 meaning을 찾게 하거나 word family를 분석하게 하면 explicit 요소가 들어간다. 판단 기준은 **learner attention의 방향**이다.

### 답안 패턴

```
The activity promotes explicit vocabulary learning because it directs learners' overt attention to the target words and helps them elaborate word knowledge through collocations and word families.
```

```
The activity supports incidental vocabulary learning because learners encounter the target words repeatedly while focusing on understanding the text rather than memorizing the words directly.
```

## ④ High-frequency Words vs Low-frequency Words

<span style="color:#3182ce">**High-frequency words**</span>는 수업 시간을 들여 정확히 알고 자주 쓰게 할 가치가 크다. Meaning-focused input, meaning-focused output, deliberate learning, fluency development를 통해 반복적으로 만나게 해야 한다.

반대로 <span style="color:#3182ce">**low-frequency words**</span>는 모든 word를 직접 가르치기보다, learner가 스스로 처리할 수 있는 <span style="color:#3182ce">**word learning strategies**</span>를 길러 주는 쪽이 효율적이다.

| | High-frequency words | Low-frequency words |
|---|---|---|
| 지도 원리 | 시간을 들여 attention 제공 | strategies for dealing with them |
| 수업 처리 | deliberate learning + repeated use | 빠르게 처리하거나 guessing strategies로 전환 |
| 활동 | fluency development, repeated output | part of speech, word parts, context clues |
| 답안 동사 | teach, recycle, practice, retrieve | infer, guess, analyze, use context |

Low-frequency words를 처리할 때는 다음 단서를 활용한다.

Part of speech, immediate context, collocation, wider textual context, word parts, word association을 보고 meaning을 추론한다.

<span style="color:#c53030">**⚠️ 함정**</span>: 모든 unknown words를 pre-teach하는 방식은 vocabulary 지도처럼 보여도 좋은 답안이 아니다. 특히 low-frequency words는 개별 암기보다 strategy training으로 처리해야 한다.

## ⑤ Classroom Techniques — Keyword Method, Semantic Mapping, Realia, Concordancing

### Keyword Method — mnemonic device

<span style="color:#3182ce">**Keyword method**</span>는 target word의 form과 meaning을 memory 안에서 연결하기 위한 <span style="color:#3182ce">**mnemonic device**</span>이다. 보통 L1이나 이미 아는 word 중 target word와 sound가 비슷한 familiar word를 찾고, target meaning과 연결되는 visual image를 만든다.

절차:

1. Target word와 sound가 비슷한 familiar word를 찾는다.
2. Familiar word와 target meaning을 연결하는 visual image를 만든다.
3. Image를 통해 target word meaning을 recall한다.

<span style="color:#c53030">**2019_A 기입10**</span> — keyword method와 mnemonic 맥락

<span style="color:#c53030">**⚠️ 함정**</span>: Keyword method는 "많이 반복해서 외우기"가 아니다. **sound link + image link + target meaning recall**이 모두 있어야 한다.

### Semantic Mapping — visual network

<span style="color:#3182ce">**Semantic mapping**</span>은 thematically related words의 relationship을 visual network로 조직하는 technique이다. Learner가 이미 아는 words를 retrieve하고, category별로 organize한 뒤, 새 vocabulary를 기존 network에 연결한다.

예를 들어 topic이 *environment*라면 learner는 *pollution, recycle, conserve, renewable energy* 등을 떠올리고 category로 묶는다. 이때 vocabulary는 isolated list가 아니라 associative network 안에서 정리된다.

| Semantic Mapping의 기능 | 답안 표현 |
|---|---|
| retrieve | learners retrieve words they already know |
| organize | learners organize related words into categories |
| visualize | learners see relationships among words |
| expand | learners connect new words to an existing network |

### Realia — actual objects

<span style="color:#3182ce">**Realia**</span>는 classroom에 가져온 actual objects/items를 활용해 vocabulary를 가르치는 방식이다. 직접 보거나 만질 수 있는 objects가 word meaning을 구체화한다.

<span style="color:#c53030">**2021 Q1**</span> — realia, supplementary materials, vocabulary teaching 맥락

답안에서는 "interesting material" 정도로 쓰지 말고, actual object가 form-meaning link를 어떻게 강화하는지 쓴다.

```
Realia helps learners connect the target word with a concrete object, making the form-meaning link more salient and memorable.
```

### Concordancing — corpus-based pattern noticing

<span style="color:#3182ce">**Concordancing**</span>은 corpus data에서 특정 lexical item이나 expression의 occurrences를 context 안에서 배열해 보여 주는 technique이다. Learner는 실제 examples를 비교하면서 grammar와 lexical units의 association, collocation, frequency, word senses를 inductively 탐색한다.

<span style="color:#c53030">**2021 Q12**</span> — corpus, lexicography, collocation, frequency 맥락
<span style="color:#c53030">**2023 B-10**</span> — collocation, concordancer 맥락

<span style="color:#c53030">**⚠️ 함정**</span>: Concordancing은 teacher가 rule을 먼저 설명하는 presentation이 아니다. Learner가 repeated examples를 보고 pattern regularity를 발견하는 <span style="color:#3182ce">**data-driven learning**</span> 성격이 강하다.

## ⑥ Multi-word Units — Collocation vs Lexical Phrases

### Collocation

<span style="color:#3182ce">**Collocation**</span>은 two or more words가 discourse에서 함께 나타나는 경향이다. *make a decision*, *commit a crime*, *strong tea*처럼 word combination의 naturalness가 핵심이다. Matching activity, gap-filling activity, concordancer-based noticing으로 지도할 수 있다.

<span style="color:#c53030">**2013 Q28**</span> — collocation과 lexical chunk 교수 맥락
<span style="color:#c53030">**2024 A-11**</span> — collocations, idioms, receptive skills 맥락

### Lexical Phrases

<span style="color:#3182ce">**Lexical phrases**</span>는 frequent use로 conventionalized된 recurring phrases or patterns이다. Lexical chunks, prefabricated routines, routine formulae, gambits와 연결되며 fluency와 pragmatic competence 발달에 도움이 된다.

<span style="color:#c53030">**2014 기입15**</span> — lexical approach와 chunks 맥락

| | Collocation | Lexical Phrases |
|---|---|---|
| 중심 | words가 함께 나타나는 likelihood | conventionalized phrase/pattern |
| 단위 | word combination | chunk, routine, gambit |
| 효과 | natural word use | fluency, pragmatic competence |
| 함정 | synonym 관계로 착각 | grammar rule이나 idiom만으로 축소 |

<span style="color:#c53030">**⚠️ 함정**</span>: Collocation은 "뜻이 특이한 표현"만 가리키지 않는다. 의미가 투명해도 함께 자주 쓰이면 collocation이다. Lexical phrases는 single word 암기가 아니라 chunk 단위 retrieval을 줄여 processing burden을 낮춘다.

## ⑦ Vocabulary Growth — noticing, retrieval, elaboration

L2 vocabulary growth activity에는 세 요소가 중요하다.

- <span style="color:#3182ce">**Noticing**</span>: useful language item을 awareness로 끌어올림
- <span style="color:#3182ce">**Retrieval**</span>: receptive/productive retrieval을 통해 다시 꺼내 봄
- <span style="color:#3182ce">**Elaboration**</span>: word를 더 많은 association과 context에 연결함

세 요소는 좋은 vocabulary activity의 점검표처럼 쓰면 된다. 예를 들어 learner가 text에서 target collocations를 underline하면 noticing, 다음 task에서 다시 쓰면 retrieval, semantic map이나 sentence writing으로 다른 contexts에 연결하면 elaboration이 된다.

### 답안 작성 패턴

```
This activity facilitates vocabulary growth because it helps learners notice the target words, retrieve them in a later task, and elaborate their word knowledge by connecting the words with related contexts.
```

```
The task goes beyond rote memorization by requiring learners to retrieve the target collocations and use them in a meaningful output task.
```

> 💡 <span style="color:#dd6b20;">**현직쌤 팁**</span>: "helps students memorize vocabulary"는 너무 약하다. 적어도 noticing, retrieval, elaboration 중 하나를 골라 mechanism으로 써야 한다.

## ⑧ 실전 판단 순서

Vocabulary 문항은 label보다 condition을 먼저 본다.

1. Vocabulary 자체에 overt attention이 있는가? → explicit learning
2. Meaningful text/communication 처리 중 repeated exposure가 있는가? → implicit/incidental learning
3. High-frequency words인가? → deliberate learning, recycling, fluency development
4. Low-frequency words인가? → guessing strategies, word analysis
5. Sound link와 image link가 있는가? → keyword method
6. Thematically related words를 visual network로 묶는가? → semantic mapping
7. Actual object를 사용해 form-meaning link를 강화하는가? → realia
8. Corpus examples를 비교해 pattern을 발견하는가? → concordancing
9. Word combination naturalness를 묻는가? → collocation
10. Chunk/routine/pattern 단위 retrieval을 묻는가? → lexical phrases

### 안전한 답안 시작

- ✅ "The activity promotes explicit vocabulary learning by directing learners' overt attention to the target words."
- ✅ "The task supports incidental vocabulary learning because learners meet the words repeatedly while focusing on meaning."
- ✅ "The activity develops vocabulary depth by having learners connect the word with its collocations and word family."
- ✅ "The concordancer helps learners notice collocation patterns and frequency through repeated corpus examples."
