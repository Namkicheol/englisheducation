# Ch.5 Methodology — 교수법 핵심 정리 | 임용영어 개념 정리

Methodology는 긴 이론 설명보다 **활동 조건 판별**이 중요하다. 활동명이 pair work, drill, task라고 주어져도 바로 믿지 말고 learner가 어떤 information을 가지고 출발하는지, 어떤 choice를 하는지, 최종 outcome이 있는지를 확인해야 한다.

연도 표기는 `docs/기출맥락_2010_2026.md`와 기존 study page에서 확인되는 범위만 사용했다.

---

## ① 개념 정의

### CLT — communicative activity 조건

<span style="color:#3182ce">**CLT**</span>는 language를 isolated form이 아니라 classroom use와 communication purpose 안에서 본다. 핵심 단서는 communicative activity, authentic material, small groups, functions and forms이다.

<span style="color:#3182ce">**Communicative activity**</span>는 보통 세 조건으로 판단한다.

| 조건 | 확인 포인트 | 예시 |
|---|---|---|
| information gap | learners가 서로 다른 information을 가지고 있는가 | Card A/B 정보가 다름 |
| learner choice | 내용이나 표현 선택권이 있는가 | 질문 순서, 표현, 응답을 조정 |
| feedback | 상대 반응이 outcome에 영향을 주는가 | 답변을 듣고 schedule/ranking 완성 |

<span style="color:#c53030">**⚠️ 함정**: pair work나 speaking activity라고 자동으로 CLT가 아니다.</span> 같은 worksheet를 보며 정해진 문장을 반복하면 information gap과 learner choice가 약하다. 반대로 controlled drill처럼 보여도 서로 다른 information을 교환해야 outcome이 완성되면 communicative한 성격을 설명할 수 있다.

<span style="color:#c53030">**기출 연결**</span>: 2010 Q16은 focus on form과 communicative activity, 2026 A-7은 communicative drill과 information gap 맥락으로 기존 study page에 정리되어 있다. `docs/기출맥락_2010_2026.md`에는 2026 B-11도 Card A/Card B를 통한 information gap 도입으로 잡혀 있다.

---

### TBLT — task의 세 조건

<span style="color:#3182ce">**TBLT**</span>에서 task는 단순 activity가 아니라 아래 조건을 가진 work plan이다.

- <span style="color:#3182ce">**primary focus on meaning**</span>: learner의 주된 관심이 target form 자체가 아니라 meaning 전달에 있음
- <span style="color:#3182ce">**natural language use process**</span>: 실제 communication과 유사한 processing이 일어남
- <span style="color:#3182ce">**clearly defined communicative outcome**</span>: 끝났을 때 확인 가능한 outcome이 있음

예를 들어 "past tense 빈칸 채우기"는 form practice에 가깝다. 반면 "지난 주말 activity를 조사해 class survey 결과를 보고하기"는 meaning focus와 outcome이 있으므로 task 판단이 가능하다.

<span style="color:#c53030">**⚠️ 함정**: TBLT는 grammar teaching을 금지하지 않는다.</span> task가 중심이고, form focus는 task 수행 중 learner language를 바탕으로 또는 task 이후 language focus 단계에서 연결될 수 있다.

<span style="color:#c53030">**기출 연결**</span>: 2017 B 서술3은 TBLT task 유형과 focus on form 통합, 2023 B-10은 task-based language test 맥락으로 기존 study page에 확인된다.

---

### Target Task vs Pedagogical Task

| | <span style="color:#3182ce">**Target Task**</span> | <span style="color:#3182ce">**Pedagogical Task**</span> |
|---|---|---|
| 위치 | classroom 밖 real-world activity | classroom 안 learning activity |
| 목적 | 실제 생활에서 수행할 일 | communicative language use 유도 |
| 예시 | hotel reservation, asking for directions | picture difference, class survey, ranking task |

<span style="color:#3182ce">**Rehearsal task**</span>는 real-world counterpart와 직접 연결된다. <span style="color:#3182ce">**Activation task**</span>는 직접 대응은 약해도 learner가 의미 중심으로 language resources를 쓰게 만든다.

## ② 기출 맥락

### CLT / information gap 계열

CLT 문항은 활동 이름보다 수정된 material이나 teacher instruction이 왜 더 communicative해졌는지를 묻는 식으로 나온다.

답안 판단 순서:

1. learners가 서로 다른 information을 가지고 출발하는가?
2. 서로 묻고 답해야 outcome이 완성되는가?
3. learner choice와 feedback이 있는가?

<span style="color:#c53030">**2026 A-7 / 2026 B-11 포인트**</span>: "communicative drill"이나 Card A/Card B가 나오면 drill이라는 단어보다 information distribution을 먼저 본다.

답안 패턴:

> The activity is communicative because Student A and Student B hold different information and must exchange it to complete the outcome.

---

### TBLT / task type 계열

TBLT는 task의 조건, task type, focus on form의 위치가 함께 묶일 수 있다.

| 포인트 | 답안 기준 | 흔한 오답 |
|---|---|---|
| task 조건 | primary focus on meaning + communicative outcome | 재미있는 activity라서 task라고 함 |
| task type | information-gap / opinion-gap / reasoning-gap process 구분 | topic만 보고 type을 찍음 |
| focus on form | task 맥락 안에서 learner language를 바탕으로 처리 | TBLT는 form을 다루면 안 된다고 함 |

<span style="color:#c53030">**2017 B 서술3 포인트**</span>: TBLT와 focus on form이 같이 나오면 "form instruction 배제"가 아니라 "meaning-focused task 안에서 form attention이 어떻게 연결되는가"를 써야 한다.

## ③ 키텀 비교

### Information-gap vs Opinion-gap vs Reasoning-gap

| | <span style="color:#3182ce">**Information-gap**</span> | <span style="color:#3182ce">**Opinion-gap**</span> | <span style="color:#3182ce">**Reasoning-gap**</span> |
|---|---|---|---|
| 핵심 | 서로 다른 information 교환 | preference, feeling, attitude 표현 | 주어진 information에서 새 information 추론 |
| outcome | missing information 완성 | 선택과 의견 비교 | route, solution, conclusion 도출 |
| 예시 | 서로 다른 timetable로 schedule 완성 | best school rule ranking | clues를 조합해 best route 찾기 |
| 함정 | 같은 자료를 보면 gap이 약함 | 정답 하나가 있으면 약함 | 단순 전달이 아니라 inference 필요 |

---

### PPP vs TBLT

| | <span style="color:#3182ce">**PPP**</span> | <span style="color:#3182ce">**TBLT**</span> |
|---|---|---|
| 출발점 | target form | task |
| 흐름 | Presentation → Practice → Production | pre-task → task cycle → language focus |
| 중심 | accuracy practice에서 production으로 이동 | task completion과 meaning-oriented communication |
| 함정 | Production이 있어도 task 중심은 아님 | form focus가 있어도 TBLT일 수 있음 |

---

### Communicative Drill vs Mechanical Drill

| | <span style="color:#3182ce">**Mechanical Drill**</span> | <span style="color:#3182ce">**Communicative Drill**</span> |
|---|---|---|
| response | 정해진 form 반복 | meaning에 따라 response 달라짐 |
| learner choice | 거의 없음 | 제한적이나 실제 선택 있음 |
| information gap | 없음 | 있을 수 있음 |

communicative drill은 controlled practice일 수 있지만, 맥락 적절성 판단이나 서로 다른 information 교환이 있으면 CLT 맥락에서 설명할 수 있다.

---

### Designer Methods — 빠른 단서

| Method | classroom clue |
|---|---|
| <span style="color:#3182ce">**Silent Way**</span> | teacher silence, learner discovery |
| <span style="color:#3182ce">**TPR**</span> | command + physical response |
| <span style="color:#3182ce">**Suggestopedia**</span> | relaxed atmosphere, suggestion |
| <span style="color:#3182ce">**CLL**</span> | counselor role, learner security |
| <span style="color:#3182ce">**Natural Approach**</span> | comprehensible input, low affective filter |

<span style="color:#c53030">**답안 팁**</span>: method name만 쓰지 말고 teacher behavior와 learner behavior를 붙인다. 예: "The activity reflects TPR because the teacher gives commands and learners demonstrate comprehension through physical response."

---

### Post-method

<span style="color:#3182ce">**Post-method**</span>는 단일 method의 처방보다 local context, teacher judgement, learner needs에 맞춘 principled decision을 강조한다. <span style="color:#3182ce">**Principled eclecticism**</span>은 여러 method를 아무렇게나 섞는 것이 아니라 coherent rationale에 따라 technique을 선택하는 것이다.

<span style="color:#c53030">**⚠️ 함정**</span>: "여러 방법을 섞었다"만으로는 부족하다. learner needs와 local context에 근거한 선택이어야 한다.

---

## ④ 답안 작성 패턴

### CLT / information gap

> The activity is communicative because it contains an information gap: each learner has different information and must exchange it to complete the outcome.

### TBLT

> This is a task because learners primarily focus on meaning and produce a clearly defined communicative outcome.

### Task type

> It is a reasoning-gap task because learners must infer a new conclusion from the given information, not simply exchange already-held information.

### Post-method

> The teacher's choice reflects principled eclecticism because the selected techniques are justified by learner needs and the local teaching context.
