# Ch.5 Methodology — 교수법 핵심 정리 | 임용영어 개념 정리

---

## ① 개념 정의

### CLT — communicative activity 조건

<span style="color:#3182ce">**CLT**</span>는 language를 isolated form이 아니라 실제 classroom use와 communication 목적 안에서 보는 접근이다. 핵심은 communicative activity, authentic material, small groups, functions and forms의 균형이다.

<span style="color:#3182ce">**Communicative activity**</span>에는 보통 세 조건이 함께 제시된다.

| 조건 | 확인 포인트 |
|---|---|
| information gap | learners가 서로 다른 information을 가지고 교환해야 함 |
| learner choice | 발화 내용이나 표현을 learner가 선택함 |
| feedback | communication 결과에 대한 반응이 있음 |

<span style="color:#c53030">**⚠️ 함정**: CLT는 "즐거운 말하기 활동" 정도로 외우면 안 된다. information gap, learner choice, feedback이 실제로 있는지 확인해야 한다.</span>

<span style="color:#c53030">**2010 Q16**</span> — focus on form과 communicative activity 맥락
<span style="color:#c53030">**2026 A-7**</span> — communicative drill과 information gap 맥락

---

### TBLT — task의 핵심 조건

<span style="color:#3182ce">**TBLT**</span>는 task completion을 중심으로 language use를 조직한다. 여기서 task는 단순 exercise가 아니라 다음 조건을 가진 work plan이다.

- <span style="color:#3182ce">**primary focus on meaning**</span>: learner의 주된 관심은 form 자체가 아니라 meaning 전달
- <span style="color:#3182ce">**natural language use process**</span>: 실제 communication과 유사한 language use
- <span style="color:#3182ce">**clearly defined communicative outcome**</span>: task 수행 후 확인 가능한 outcome 존재

<span style="color:#c53030">**⚠️ 함정**: form 연습을 task라고 부르려면 부족하다. meaning focus와 communicative outcome이 있어야 TBLT의 task로 판단할 수 있다.</span>

<span style="color:#c53030">**2017 B 서술3**</span> — TBLT task 유형과 form focus 통합 맥락
<span style="color:#c53030">**2023 B-10**</span> — task-based language test 맥락

---

### Target Task vs Pedagogical Task

| | <span style="color:#3182ce">**Target Task**</span> | <span style="color:#3182ce">**Pedagogical Task**</span> |
|---|---|---|
| 장소 | classroom 밖 real-world activity | classroom 안 activity |
| 목적 | 실제 생활에서 수행할 task | communicative language use 유도 |
| 예시 판단 | real-world counterpart가 핵심 | teaching 목적에 맞게 설계된 활동 |

<span style="color:#3182ce">**Rehearsal task**</span>는 real-world counterpart와 명확한 관계가 있고, <span style="color:#3182ce">**Activation task**</span>는 직접 대응이 약하지만 language use를 활성화한다.

---

## ② 기출 맥락

### Information-gap — 2026 A-7 확인 포인트

<span style="color:#c53030">**2026 A-7**</span>에서 확인되는 핵심은 활동 이름보다 실제 조건이다. learners가 서로 다른 information을 가지고 있고, communication을 통해 missing information을 채워야 하면 <span style="color:#3182ce">**information-gap**</span> 성격이 강하다.

답안 판단 순서:
1. learners가 같은 information을 가지고 있는가?
2. 서로 다른 information을 교환해야 task가 완성되는가?
3. 단순 repetition이나 mechanical drill이 아니라 communicative outcome이 있는가?

<span style="color:#c53030">**⚠️ 함정**: pair work라고 해서 자동으로 information-gap이 아니다. 서로에게 필요한 information이 다르게 배분되어 있어야 한다.</span>

---

### TBLT — 2017 B 서술3 / 2023 B-10 확인 포인트

TBLT 관련 문항은 주로 task의 조건, task type, form focus의 위치를 함께 묻는다.

| 포인트 | 답안 기준 |
|---|---|
| task 조건 | primary focus on meaning + communicative outcome |
| task type | information-gap, opinion-gap, reasoning-gap 구분 |
| form focus | task 수행 중 또는 이후 learner language를 바탕으로 다룰 수 있음 |

<span style="color:#c53030">**⚠️ 함정**: TBLT는 grammar teaching을 배제한다는 식으로 단순화하면 안 된다. task가 중심이고, form focus는 task 맥락 안에서 필요에 따라 연결된다.</span>

## ③ 키텀 비교

### Information-gap vs Opinion-gap vs Reasoning-gap

| | <span style="color:#3182ce">**Information-gap**</span> | <span style="color:#3182ce">**Opinion-gap**</span> | <span style="color:#3182ce">**Reasoning-gap**</span> |
|---|---|---|---|
| 핵심 | information 교환 | preference, feeling, attitude 교환 | 주어진 information에서 새 information 추론 |
| outcome | missing information 완성 | 의견 표현과 비교 | inference process를 통한 결과 도출 |
| 판단 단서 | 서로 다른 자료, picture, schedule | personal preference, ranking, choice | route 찾기, 문제 해결, 결론 도출 |

<span style="color:#3182ce">**Reasoning-gap**</span>은 단순 information 전달이 아니라 inference process가 필요하다는 점이 핵심이다.

---

### PPP vs TBLT

| | <span style="color:#3182ce">**PPP**</span> | <span style="color:#3182ce">**TBLT**</span> |
|---|---|---|
| 흐름 | Presentation → Practice → Production | pre-task → task cycle → language focus |
| 출발점 | target form 제시 | task 수행 |
| 장점 | accuracy focus, 초급자에게 구조 제공 | meaning-oriented communication |
| 주의점 | communication이 후반부에 제한될 수 있음 | task 조건이 약하면 단순 activity가 될 수 있음 |

<span style="color:#c53030">**⚠️ 함정**: PPP의 Production과 TBLT의 task는 같지 않다. PPP는 form 제시 후 산출로 이동하고, TBLT는 task completion이 수업 조직의 중심이다.</span>

---

### Designer Methods — 빠른 구분

| Method | 핵심 단서 |
|---|---|
| <span style="color:#3182ce">**Silent Way**</span> | learner discovery, teacher silence |
| <span style="color:#3182ce">**TPR**</span> | command와 physical response |
| <span style="color:#3182ce">**Suggestopedia**</span> | relaxed atmosphere, suggestion |
| <span style="color:#3182ce">**CLL**</span> | counselor role, learner security |
| <span style="color:#3182ce">**Natural Approach**</span> | comprehensible input, low affective filter |

Designer Methods는 이름보다 classroom technique과 learner/teacher role을 단서로 잡아야 한다.

## ④ 수험 활용 팁

### Post-method — principled eclecticism

<span style="color:#3182ce">**Post-method**</span> 관점은 단일 method의 처방보다 local context, teacher judgement, learner needs에 맞춘 principled decision을 강조한다.

<span style="color:#3182ce">**Principled eclecticism**</span>은 여러 방법을 아무렇게나 섞는 것이 아니다. coherent rationale에 따라 technique을 선택하는 것이다.

<span style="color:#c53030">**⚠️ 함정**: eclecticism = random mixing으로 이해하면 오답. Post-method에서는 teacher autonomy와 local context를 근거로 한 선택이 중요하다.</span>

---

### Methodology 답안 작성 패턴

Methodology 문항은 용어를 외우는 것보다 classroom condition을 근거로 판단하는 방식이 자주 요구된다.

답안 틀:

> "(개념)은/는 (핵심 조건)을 가지므로, 제시된 활동은 (개념)에 해당한다."

예시:

> Information-gap task는 learners가 서로 다른 information을 가지고 communication을 통해 missing information을 완성한다는 점에서 제시된 pair activity와 연결된다.
