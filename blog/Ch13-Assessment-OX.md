# [영어교육론] Ch.13 Assessment OX 20문항 — 해설 완전 정복

Ch.13 Assessment의 핵심 개념을 OX 문항으로 점검합니다. Practicality, Reliability, Validity, Authenticity, Interactiveness, Washback, Test Types, Alternative Assessment, Scoring and Items까지 — 비슷한 assessment terms를 조건과 classroom use 중심으로 구분합니다.

---

## Q1. Practicality — ✅ O

> *"Practicality is best understood as financial, time, administration constraints, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**Practicality**</span>의 핵심은 financial limitation, time constraint, ease of administration입니다.

좋은 test라도 비용이 과도하거나, 시간이 너무 오래 걸리거나, administration이 복잡하면 classroom assessment로 쓰기 어렵습니다.

---

## Q2. Practicality Misconception — ❌ X

> *"Practicality can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. <span style="color:#3182ce">**Practicality**</span>는 다른 assessment quality와 구분됩니다.

<span style="color:#c53030">**함정**</span>: Practicality는 "좋은 평가인가"를 포괄적으로 묻는 말이 아니라 financial, time, administration constraints를 묻는 개념입니다.

---

## Q3. Reliability — ✅ O

> *"Reliability is best understood as consistent and dependable results, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**Reliability**</span>는 test가 consistent and dependable results를 주는 정도입니다.

Internal-consistency, student, test administration, intra-rater, inter-rater, test-retest, equivalent-forms, split-half reliability처럼 consistency가 흔들리는 지점을 구분해야 합니다.

<span style="color:#c53030">**2014 기입10**</span> 출제 영역

---

## Q4. Reliability Misconception — ❌ X

> *"Reliability can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. <span style="color:#3182ce">**Reliability**</span>는 consistent and dependable results가 핵심입니다.

Reliability가 높다고 해서 <span style="color:#3182ce">**Validity**</span>가 자동으로 보장되는 것은 아닙니다. 일관되게 틀린 construct를 측정할 수도 있기 때문입니다.

---

## Q5. Validity — ✅ O

> *"Validity is best understood as content, face, construct, criterion-related, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**Validity**</span>는 test가 측정하려는 것을 실제로 측정하는 정도입니다.

Content, face, construct, criterion-related validity를 구분하고, 문항에서 intended construct와 assessment use를 확인해야 합니다.

---

## Q6. Validity Misconception — ❌ X

> *"Validity can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. <span style="color:#3182ce">**Validity**</span>는 단순 용어 문제가 아니라 assessment instrument와 intended construct의 관계를 묻습니다.

예를 들어 speaking competence를 paper-and-pencil multiple-choice test로만 측정하면 content validity가 낮아질 수 있습니다.

---

## Q7. Authenticity and Interactiveness — ✅ O

> *"Authenticity and Interactiveness is best understood as target language use와 individual characteristics involvement, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**Authenticity**</span>는 target language use task와의 대응, <span style="color:#3182ce">**Interactiveness**</span>는 learner의 individual characteristics involvement가 핵심입니다.

Natural language, contextualized items, meaningful topic은 Authenticity의 단서가 될 수 있습니다.

<span style="color:#c53030">**2012 Q25**</span> 출제 영역

---

## Q8. Authenticity and Interactiveness Misconception — ❌ X

> *"Authenticity and Interactiveness can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. <span style="color:#3182ce">**Authenticity**</span>와 <span style="color:#3182ce">**Interactiveness**</span>는 구분해야 합니다.

Authenticity는 task와 target language use의 대응이고, Interactiveness는 language ability, topical knowledge, affective schemata 같은 learner characteristics가 얼마나 관여하는지입니다.

---

## Q9. Washback — ✅ O

> *"Washback is best understood as testing이 teaching/learning에 미치는 영향, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**Washback effect**</span>는 testing이 teaching과 learning에 미치는 영향입니다.

Useful diagnoses와 specific feedback은 beneficial washback을 만들 수 있습니다.

<span style="color:#c53030">**2018 기입7**</span> 출제 영역

---

## Q10. Washback Misconception — ❌ X

> *"Washback can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. <span style="color:#3182ce">**Washback**</span>는 test가 instruction과 learner behavior에 어떤 영향을 미치는지를 묻습니다.

Simple letter grade만 제공하면 learner가 무엇을 고쳐야 하는지 알기 어렵기 때문에 washback이 약할 수 있습니다.

---

## Q11. Test Types — ✅ O

> *"Test Types is best understood as formative/summative, norm/criterion, direct/indirect, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**Test Types**</span>는 목적과 score interpretation을 기준으로 구분합니다.

<span style="color:#3182ce">**Formative assessment**</span>는 instruction 과정 중 learner learning을 scaffold하고, <span style="color:#3182ce">**Summative assessment**</span>는 course end에서 learning outcome을 document합니다.

<span style="color:#c53030">**2011 Q29**</span> 출제 영역

---

## Q12. Test Types Misconception — ❌ X

> *"Test Types can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. <span style="color:#3182ce">**Test Types**</span>는 label이 아니라 purpose, interpretation, classroom use로 구분합니다.

<span style="color:#3182ce">**Norm-referenced testing**</span>은 test takers끼리 비교하고, <span style="color:#3182ce">**Criterion-referenced testing**</span>은 mastery criterion에 비추어 performance를 해석합니다.

<span style="color:#c53030">**2010 Q25**</span> 출제 영역

---

## Q13. Alternative Assessment — ✅ O

> *"Alternative Assessment is best understood as portfolio, self-assessment, performance-based assessment, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**Alternative Assessment**</span>는 portfolio, self-assessment, performance-based assessment 등을 포함합니다.

<span style="color:#3182ce">**Portfolio**</span>는 learner work의 purposeful collection으로 progress와 achievement를 보여 줍니다.

<span style="color:#c53030">**2010 Q29 / 2016 서술6**</span> 출제 영역

---

## Q14. Alternative Assessment Misconception — ❌ X

> *"Alternative Assessment can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. <span style="color:#3182ce">**Alternative Assessment**</span>는 process, production, reflection, teacher judgement 같은 특징을 중심으로 봐야 합니다.

Portfolio assessment는 formal이면서 formative일 수 있고, Self-assessment는 learner autonomy와 intrinsic motivation을 촉진할 수 있습니다.

---

## Q15. Scoring and Items — ✅ O

> *"Scoring and Items is best understood as holistic/analytic scoring, MC guidelines, item analysis, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**Holistic scoring**</span>은 single score를 빠르게 제공하고, <span style="color:#3182ce">**Analytic scoring**</span>은 components를 따로 rating하여 diagnostic feedback을 제공합니다.

Analytic scoring은 시간이 더 걸리지만 formative feedback과 strengths/weaknesses 파악에 유용합니다.

<span style="color:#c53030">**2021 논술2**</span> 출제 영역

---

## Q16. Scoring and Items Misconception — ❌ X

> *"Scoring and Items can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. Scoring 방식과 item guideline은 서로 다른 판단 기준을 가집니다.

Selected-response item은 declarative knowledge와 beginning level learner 평가에 유용하지만 guessing과 distractor quality 문제가 있습니다. Stem은 concise and simple해야 하며, distractors는 같은 grammatical/semantic category에 속해야 합니다.

<span style="color:#c53030">**2023 B-11**</span> 출제 영역

---

## Q17. Practicality Review — ❌ X

> *"A learner can identify Practicality only by memorizing the label, without checking examples or classroom conditions."*

틀립니다. <span style="color:#3182ce">**Practicality**</span>는 label만 외우기보다 classroom conditions를 함께 확인해야 합니다.

financial limitation, time constraint, ease of administration이 보이면 Practicality를 우선 의심합니다.

---

## Q18. Reliability Review — ❌ X

> *"A learner can identify Reliability only by memorizing the label, without checking examples or classroom conditions."*

틀립니다. <span style="color:#3182ce">**Reliability**</span>는 examples와 scoring/administering conditions를 확인해야 합니다.

rater가 바뀌어도 score가 유지되는지, 같은 learner가 비슷한 조건에서 비슷한 결과를 얻는지 같은 consistency 단서가 중요합니다.

---

## Q19. Validity Review — ❌ X

> *"A learner can identify Validity only by memorizing the label, without checking examples or classroom conditions."*

틀립니다. <span style="color:#3182ce">**Validity**</span>는 intended construct와 assessment task의 관계를 확인해야 합니다.

문항이 무엇을 측정한다고 주장하는지, 실제 task가 그 construct를 충분히 대표하는지를 함께 보아야 합니다.

---

## Q20. Authenticity and Interactiveness Review — ❌ X

> *"A learner can identify Authenticity and Interactiveness only by memorizing the label, without checking examples or classroom conditions."*

틀립니다. <span style="color:#3182ce">**Authenticity**</span>와 <span style="color:#3182ce">**Interactiveness**</span>는 examples와 task conditions를 확인해야 합니다.

Target language use와 얼마나 대응하는지, learner의 language ability와 topical knowledge가 얼마나 관여하는지가 판단 기준입니다.
