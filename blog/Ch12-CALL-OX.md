# [영어교육론] Ch.12 CALL · Material OX 20문항 — 해설 완전 정복

Ch.12 OX는 단어 뜻만 묻는 것처럼 보이지만 실제로는 **tool, condition, learner behavior, assessment purpose**를 구분하는 연습이다. 특히 Corpus and Concordance, Data-driven Learning, CMC, E-learning, CAT, CALL Approaches, Material은 서로 붙어서 나오기 때문에 "computer를 썼다" 수준의 판단으로는 부족하다.

아래 해설은 각 OX 문항을 단순 정오 확인이 아니라, **왜 그 판단이 되는지**, **어떤 함정 선지가 가능한지**, **서술형 답안에서는 어떻게 써야 하는지**까지 연결해 정리한다.

---

## Q1. Corpus and Concordance — ✅ O

> *"Corpus and Concordance is best understood as corpus, concordancer, KWIC, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**Corpus and Concordance**</span>의 핵심은 corpus, concordancer, KWIC입니다. Corpus는 authentic texts의 large collection이고, concordancer는 target word나 expression이 나타나는 context를 배열해 보여 주는 software입니다. KWIC는 keyword in context format으로 target item 주변의 usage pattern을 한눈에 비교하게 해 줍니다.

서술형에서는 "students used a computer"가 아니라 다음처럼 써야 합니다.

```
The concordancer helps learners compare authentic examples of the target expression in context.
```

---

## Q2. Corpus and Concordance — ❌ X

> *"Corpus and Concordance can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. Corpus and Concordance는 단순 label이 아니라 **tool and data condition**을 갖는 개념입니다. Corpus, concordancer, concordance lines, KWIC가 보이면 usage examples를 어떻게 배열하고 비교하게 하는지 봐야 합니다.

⚠️ **함정**: Corpus and Concordance를 Data-driven Learning과 완전히 같은 말로 처리하면 답안이 흐려집니다. Concordancer는 tool이고, Data-driven Learning은 learner가 그 tool로 pattern을 찾아 rule을 형성하는 learning procedure입니다.

---

## Q3. Data-driven Learning — ✅ O

> *"Data-driven Learning is best understood as learner가 pattern을 비교하고 inductive rule 형성, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**Data-driven Learning**</span>은 learner가 corpus data를 보고 regularity를 탐색한 뒤 rule을 <span style="color:#3182ce">**inductively**</span> 형성하는 방식입니다. 핵심은 teacher explanation이 아니라 learner discovery입니다.

예를 들어 learner가 `remember + -ing`과 `remember + to-infinitive` 예문을 비교해 meaning difference를 찾는다면, 이는 Data-driven Learning의 전형적인 장면입니다.

---

## Q4. Data-driven Learning — ❌ X

> *"Data-driven Learning can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. Data-driven Learning은 인접 개념과 구분되는 learner behavior가 있습니다. Learner가 examples를 비교하고, pattern을 찾고, rule을 formulate해야 합니다.

⚠️ **오답 선지 패턴**: "The teacher first explains the rule and then asks students to apply it to corpus examples." 이런 문장은 Data-driven Learning으로 보기 어렵습니다. Corpus를 쓰더라도 teacher-led rule presentation이면 핵심 mechanism이 달라집니다.

---

## Q5. CMC — ✅ O

> *"CMC is best understood as synchronous vs asynchronous communication, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**CMC**</span>는 computer-mediated communication이고, 임용에서는 synchronous / asynchronous 구분이 먼저입니다.

- <span style="color:#3182ce">**Synchronous CMC**</span>: chat, text-based conferencing, audio/video conferencing처럼 real-time response가 가능
- <span style="color:#3182ce">**Asynchronous CMC**</span>: e-mail, bulletin board system처럼 시간차 communication 가능

<span style="color:#c53030">**2026 B-5**</span>는 `CALL`, `peer feedback`, `fluency`가 함께 정리된 맥락입니다. CALL product가 peer feedback을 가능하게 하는지, fluency practice와 연결되는지 확인하는 식으로 읽어야 합니다.

---

## Q6. CMC — ❌ X

> *"CMC can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. CMC는 communication timing과 interaction condition이 핵심입니다. Chat은 learner가 즉시 clarification request나 confirmation check를 할 수 있지만, e-mail은 reflection과 revision time을 더 많이 줍니다.

답안 패턴:

```
The activity uses synchronous CMC because learners interact in real time.
This can promote immediate negotiation of meaning and peer response.
```

---

## Q7. E-learning — ✅ O

> *"E-learning is best understood as online, distance, open, blended learning, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**E-learning**</span> 계열은 delivery condition으로 나눠야 합니다.

| 용어 | 핵심 |
|---|---|
| Distance learning | technology를 통한 remote learning |
| Online learning | Internet-based learning |
| Open learning | learner autonomy와 access flexibility |
| Blended learning | online + face-to-face course delivery의 mixture |

OX에서는 "Internet을 썼다"와 "face-to-face와 online을 섞었다"를 구분하는 선지가 자주 함정이 됩니다.

---

## Q8. E-learning — ❌ X

> *"E-learning can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. E-learning 계열 용어는 이름이 비슷해도 조건이 다릅니다. 특히 <span style="color:#3182ce">**Blended learning**</span>은 online component만 있으면 되는 것이 아니라 face-to-face component와 결합되어야 합니다.

⚠️ **함정 정리**: "online learning"은 Internet 기반이라는 delivery channel이 핵심이고, "open learning"은 learner autonomy와 access가 핵심입니다. 둘을 같은 말로 쓰지 않습니다.

---

## Q9. CAT — ✅ O

> *"CAT is best understood as performance에 따라 item이 조정되는 computer-adaptive testing, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**CAT**</span>는 이전 item performance를 바탕으로 다음 item difficulty가 조정되는 computer-adaptive testing입니다. 모든 test-taker에게 같은 item sequence를 주는 시험과 다릅니다.

<span style="color:#c53030">**2023 A-4**</span>는 `computer adaptive testing (CAT)`, `item response theory (IRT)`, `item bank`, `ability estimation`이 핵심 용어로 정리된 문항입니다. 그래서 CAT 답안에는 adaptive item selection과 ability estimation을 함께 잡으면 좋습니다.

---

## Q10. CAT — ❌ X

> *"CAT can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. CAT는 단순 computer-based test가 아닙니다. 핵심은 **test-taker performance에 따라 subsequent items가 선택되는가**입니다.

주의점도 함께 기억해야 합니다.

- Individual proficiency를 빠르게 추정할 수 있음
- Item bank quality가 중요함
- Open-ended questions 활용이 어려움
- <span style="color:#3182ce">**construct validity**</span> 문제가 생길 수 있음

답안 한 줄:

```
The test is computer-adaptive because each subsequent item is selected based on the test-taker's previous performance.
```

---

## Q11. CALL Approaches — ✅ O

> *"CALL Approaches is best understood as behavioristic vs constructivist CALL, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**CALL Approaches**</span>는 behavioristic CALL과 constructivist CALL의 learner role 차이가 핵심입니다.

<span style="color:#3182ce">**Behavioristic CALL**</span>은 drills, practice, tutorial explanation, corrective feedback을 제공하는 programmed instruction 쪽입니다. 반면 <span style="color:#3182ce">**Constructivist CALL**</span>은 authentic materials와 communication opportunities를 통해 learner가 exploration, collaboration, inquiry-based learning을 수행하도록 돕습니다.

<span style="color:#c53030">**2024 A-12**</span>는 `CALL`, `virtual environment`, `collaborative learning` 맥락으로 정리되어 있어 Constructivist CALL 쪽 판단과 잘 연결됩니다.

---

## Q12. CALL Approaches — ❌ X

> *"CALL Approaches can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. CALL Approaches는 computer와 learner의 역할이 달라집니다. 같은 digital tool이라도, learner가 정답/오답 feedback을 받으며 반복 practice를 하면 Behavioristic CALL 쪽이고, learner가 authentic resources를 탐색하며 협력 task를 수행하면 Constructivist CALL 쪽입니다.

⚠️ **시험 함정**: "multimedia"라는 말만 보고 constructivist라고 판단하지 않습니다. Multimedia가 drill delivery에 쓰이면 Behavioristic CALL일 수 있습니다.

---

## Q13. Material — ✅ O

> *"Material is best understood as authentic material and evaluation, so it should be interpreted within its instructional or assessment context."*

맞습니다. <span style="color:#3182ce">**Material**</span> 영역에서는 authentic materials, material adaptation, material evaluation을 instructional context와 assessment context 안에서 보아야 합니다.

<span style="color:#3182ce">**Authentic materials**</span>는 real-life language exposure를 제공하지만, 그 자체로 항상 적절한 것은 아닙니다. Learner level, objective, context에 맞게 조정되어야 하며, evaluation criteria도 분명해야 합니다.

---

## Q14. Material — ❌ X

> *"Material can be safely treated as the same as any neighboring concept because the distinction is mostly terminological."*

틀립니다. Material은 단순 자료 이름이 아니라 objectives, learner needs, skill balance, authenticity, practicality, evaluation criteria와 연결해 판단해야 합니다.

<span style="color:#c53030">**2023 A-8**</span>은 `needs analysis`, `material adaptation`, `tap into students' lives`가 함께 정리되어 있습니다. 이런 문항에서는 "자료를 바꿨다"만 쓰지 말고, 무엇을 왜 바꿨는지 써야 합니다.

답안 패턴:

```
The teacher adapts the material by modifying the task topic based on learner needs.
This makes the activity more relevant because it taps into students' lives.
```

---

## Q15. Corpus and Concordance — ❌ X

> *"A learner can identify Corpus and Concordance only by memorizing the label, without checking examples or classroom conditions."*

틀립니다. Corpus and Concordance는 label 암기가 아니라 examples와 classroom use를 확인해야 합니다. Target word가 central column에 배열되어 있고 learner가 surrounding context를 비교한다면 KWIC/concordance evidence입니다.

<span style="color:#c53030">**2023 B-10**</span>은 `collocation`, `grammar (lexical aspect)`, `concordancer`가 함께 정리된 문항입니다. Collocation처럼 usage pattern을 확인하는 장면에서는 concordancer evidence를 놓치면 안 됩니다.

---

## Q16. Data-driven Learning — ❌ X

> *"A learner can identify Data-driven Learning only by memorizing the label, without checking examples or classroom conditions."*

틀립니다. Data-driven Learning은 learner behavior가 핵심입니다. Learner가 target word의 usage examples를 비교하고, pattern regularity를 찾아 rule을 inductively formulate하는지 확인해야 합니다.

OX에서 다음 표현이 보이면 Data-driven Learning 쪽으로 강하게 의심합니다.

- compare concordance lines
- discover regularities
- formulate rules
- notice form-meaning patterns
- reduce reliance on prescriptive grammar presentation

---

## Q17. CMC — ❌ X

> *"A learner can identify CMC only by memorizing the label, without checking examples or classroom conditions."*

틀립니다. CMC는 synchronous vs asynchronous condition을 함께 보아야 합니다. 같은 peer feedback이라도 실시간 chat feedback인지, bulletin board에 올린 draft에 delayed feedback을 주는지에 따라 해석이 달라집니다.

서술형에서는 이렇게 압축할 수 있습니다.

```
The digital product supports peer feedback by allowing learners to exchange responses through CMC.
If the exchange occurs in real time, it is synchronous CMC; if learners respond later, it is asynchronous CMC.
```

---

## Q18. E-learning — ❌ X

> *"A learner can identify E-learning only by memorizing the label, without checking examples or classroom conditions."*

틀립니다. E-learning 계열은 delivery mode와 learner autonomy 조건을 봐야 합니다. Online learning, distance learning, open learning, blended learning이 모두 "technology 사용"으로 묶일 수는 있지만, 답안에서는 서로 바꾸어 쓰면 안 됩니다.

⚠️ **한 줄 구분**: Blended learning = online + face-to-face. 이 조건이 없으면 blended라고 쓰지 않습니다.

---

## Q19. CAT — ❌ X

> *"A learner can identify CAT only by memorizing the label, without checking examples or classroom conditions."*

틀립니다. CAT는 test design의 mechanism을 봐야 합니다. Item bank에서 next item이 learner performance에 따라 선택되는지, ability estimation이 이루어지는지가 핵심입니다.

단순히 "computer로 보는 시험"이면 computer-based test일 수는 있지만, CAT라고 단정할 수 없습니다. Adaptive item selection이 evidence로 제시되어야 합니다.

---

## Q20. CALL Approaches — ❌ X

> *"A learner can identify CALL Approaches only by memorizing the label, without checking examples or classroom conditions."*

틀립니다. CALL Approaches는 label보다 purpose, learner role, teacher role, task condition을 비교해야 합니다.

정리하면:

- <span style="color:#3182ce">**Behavioristic CALL**</span>: drills, programmed instruction, corrective feedback, accuracy practice
- <span style="color:#3182ce">**Constructivist CALL**</span>: authentic materials, communication opportunities, exploration, collaboration

<span style="color:#c53030">**최종 함정**</span>: "computer + feedback"이면 항상 constructivist가 아니다. Feedback이 right/wrong drill feedback이면 Behavioristic CALL이고, peer response나 collaborative revision이면 Constructivist CALL 또는 CMC 맥락으로 볼 수 있다.

---

## 마무리: Ch.12 OX를 푸는 세 질문

1. 이 선지의 핵심은 tool인가, procedure인가?
   - Concordancer는 tool, Data-driven Learning은 procedure.

2. Communication timing은 어떻게 되는가?
   - Real-time이면 synchronous CMC, delayed response면 asynchronous CMC.

3. Learner role은 무엇인가?
   - Programmed practice면 Behavioristic CALL, exploration/collaboration이면 Constructivist CALL.

> 💡 <span style="color:#dd6b20">**현직쌤 팁**</span>: Ch.12는 "정의 쓰기"보다 "evidence 붙이기"가 점수다. 답안에 `because it enables learners to...`, `by providing...`, `based on the learner's performance...`를 넣으면 채점 포인트가 선명해진다.
