# Ch.13 Assessment — 평가 개념 완전 정복 | 임용영어 개념 정리

## ① 개념 정의

### Assessment Qualities — Practicality, Reliability, Validity

Ch.13 Assessment는 용어 암기보다 **어떤 조건에서 어떤 quality를 묻는지**가 핵심입니다. 특히 <span style="color:#3182ce">**Practicality**</span>, <span style="color:#3182ce">**Reliability**</span>, <span style="color:#3182ce">**Validity**</span>는 서로 붙어서 출제되기 쉽습니다.

| | <span style="color:#3182ce">**Practicality**</span> | <span style="color:#3182ce">**Reliability**</span> | <span style="color:#3182ce">**Validity**</span> |
|---|---|---|---|
| 핵심 | 실행 가능성 | consistent and dependable results | measures what it is supposed to measure |
| 판단 기준 | financial limitation, time constraint, ease of administration | scoring consistency, administration consistency, rater consistency | content, face, construct, criterion-related |
| 함정 | 좋은 test라도 운영 불가능하면 낮음 | Reliability가 높아도 Validity가 자동 보장되지는 않음 | 목적과 construct가 맞아야 함 |

<span style="color:#c53030">**2014 기입10**</span> — reliability, validity, washback 맥락 출제 확인

---

### Validity Types — content, construct, face, criterion-related

<span style="color:#3182ce">**Content validity**</span>는 assessment content가 course objective와 domain을 representative하게 sample하는 정도입니다. 예를 들어 speaking competence를 paper-and-pencil multiple-choice test로만 측정하면 content validity가 낮습니다.

<span style="color:#3182ce">**Construct validity**</span>는 assessment instrument가 정의된 theoretical construct를 제대로 측정하는 정도입니다. Oral interview score를 pronunciation과 grammar만으로 결정하면 intended construct를 충분히 측정하지 못할 수 있습니다.

<span style="color:#3182ce">**Face validity**</span>는 test-taker가 test를 그럴듯하고 적절하다고 받아들이는 정도입니다. <span style="color:#3182ce">**Concurrent validity**</span>와 <span style="color:#3182ce">**Predictive validity**</span>는 criterion-related validity와 연결됩니다.

<span style="color:#c53030">**⚠️ 함정**: Validity는 "좋아 보이는 test"가 아니라 **intended construct와 use**에 맞는지를 묻습니다.</span>

---

## ② 기출 맥락

### Authenticity and Interactiveness

<span style="color:#3182ce">**Authenticity**</span>는 test task가 target language use task의 features와 대응하는 정도입니다. Natural language, contextualized items, thematic organization, meaningful topic이 단서가 됩니다.

<span style="color:#3182ce">**Interactiveness**</span>는 test task 수행에 learner의 language ability, topical knowledge, affective schemata 같은 individual characteristics가 관여하는 정도입니다.

<span style="color:#c53030">**2012 Q25**</span> — portfolio와 authentic assessment 맥락 출제 확인

<span style="color:#c53030">**⚠️ 함정**: Authenticity는 실제 사용 상황과의 대응, Interactiveness는 learner characteristics의 관여 정도입니다. 둘을 같은 말처럼 처리하면 안 됩니다.</span>

---

### Washback — test가 수업을 바꾸는 방식

<span style="color:#3182ce">**Washback effect**</span>는 testing이 teaching과 learning에 미치는 영향입니다.

Useful diagnoses와 specific feedback은 beneficial washback을 만들 수 있습니다. 반대로 simple letter grade만 제공하면 learner가 무엇을 고쳐야 하는지 알기 어렵기 때문에 washback이 약합니다.

<span style="color:#c53030">**2018 기입7**</span> — assessment, washback, formative 맥락 출제 확인

## ③ 키텀 비교

### Formative vs Summative

| | <span style="color:#3182ce">**Formative assessment**</span> | <span style="color:#3182ce">**Summative assessment**</span> |
|---|---|---|
| 시점 | instruction 과정 중 | course end |
| 목적 | learner learning scaffold | learning outcome document |
| feedback | 구체적 feedback 중요 | 최종 achievement 확인 |

<span style="color:#c53030">**2011 Q29**</span> — formative assessment와 feedback 맥락 출제 확인

---

### Norm-referenced vs Criterion-referenced

| | <span style="color:#3182ce">**Norm-referenced testing**</span> | <span style="color:#3182ce">**Criterion-referenced testing**</span> |
|---|---|---|
| 기준 | 다른 test takers와 비교 | mastery criterion과 비교 |
| score 해석 | rank order, percentile, relative standing | learning goals 관련 progress |
| classroom use | 선발·서열화 맥락 | qualitative feedback과 목표 도달 확인 |

<span style="color:#c53030">**2010 Q25**</span> — norm-referenced test와 criterion-referenced test 비교 출제 확인

### Purpose-based Tests

| <span style="color:#3182ce">**Test type**</span> | 핵심 기능 |
|---|---|
| <span style="color:#3182ce">**Proficiency test**</span> | prior instruction과 무관한 overall proficiency 확인 |

## ④ 수험 활용 팁

### Portfolio and Self-assessment

<span style="color:#3182ce">**Portfolio**</span>는 learner work의 purposeful collection으로 progress와 achievement를 보여 줍니다. Process-oriented, formative, reflective이며 production과 teacher judgement를 중시합니다.

<span style="color:#3182ce">**Self-assessment**</span>는 learner가 자신의 process, strategies, outcomes를 평가하는 alternative assessment입니다. Learner autonomy와 intrinsic motivation을 촉진하지만 checklist를 구체화하고 conferencing을 병행해야 합니다.

<span style="color:#c53030">**2010 Q29**</span> — portfolio assessment와 formative assessment 출제 확인
<span style="color:#c53030">**2016 서술6**</span> — portfolio와 self-assessment 출제 확인

---

### Holistic vs Analytic Scoring

<span style="color:#3182ce">**Holistic scoring**</span>은 single score를 빠르게 제공합니다. 채점 시간이 짧지만 learner의 strengths/weaknesses를 세부적으로 보여 주기 어렵습니다.

<span style="color:#3182ce">**Analytic scoring**</span>은 components를 따로 rating하여 diagnostic feedback을 제공합니다. 시간이 더 걸리지만 formative feedback에 유리합니다.

<span style="color:#c53030">**2021 논술2**</span> — rubric, feedback, writing assessment 맥락 출제 확인

---

### Selected-response Item Guidelines

Selected-response item은 declarative knowledge와 beginning level learner 평가에 유용하지만 guessing과 distractor quality 문제가 있습니다.

핵심 guideline:

1. Stem은 concise and simple해야 합니다.
2. 하나의 clearly formulated problem만 물어야 합니다.
3. Distractors는 같은 grammatical/semantic category에 속해야 합니다.

<span style="color:#c53030">**2023 B-11**</span> — selected-response item guideline 맥락 출제 확인
